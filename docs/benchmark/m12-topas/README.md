# M12 ベンチマーク: TOPAS バックエンド vs GSAS-II

同一の実データ・同一の構造ファイルを両エンジンで自動 Rietveld にかけた結果。
**両エンジンが同じ格子・同じ相分率に落ちるか**が最重要の観測点であり、
食い違えばどちらかにバグがある。

測定日: 2026-07-31 (#172-#174 対応後) / TOPAS 7.0.1.7 (tc.exe) / GSAS-II (ソースツリー)

## 結果

| # | 系 | GSAS-II | TOPAS | 合格基準 | 判定 |
|---|---|---|---|---|---|
| T1 | fluoroapatite 単相ラボ X 線 (P6₃/m) | 9.83% | **10.45%** | ≤12% | ✅ |
| T2 | garnet 単相 CW 中性子 (Ia-3d, Fe/Al 混合占有) | 4.33% | **5.54%** | ≤6.5% | ✅ |
| T3 | PbSO4 X 線 (Pnma, 単独ヒストグラム) | 11.0% (joint の X 内訳) | **8.11%** | — | ✅ GSAS を上回る |
| T3-joint | PbSO4 X 線+CW 中性子 joint | 6.66% | **8.29%** | ≤8% | ⚠️ 僅差で未達 |
| T4 | NAC+CaF2 TOF×2+放射光 多相 | ~12.8% | **30.9%** | ≤15% | ❌ 未達 |

いずれも既定レシピ (`build_topas_recipe`) の結果。**選択配向 (`preferred_orientation`) を
1 段足すと更に下がる** (Lorentz 修正前の測定で T3 単独 8.09→7.89% / T3-joint 8.30→8.10% /
garnet 12.34→11.68%) が、既定レシピには載せていない (opt-in 段)。

### 両エンジンの一致 (最重要の観測点)

- **T2 garnet の混合占有**: TOPAS が 16a Fe 0.588/Al 0.412・24d Al 0.708/Fe 0.292。
  GSAS-II は 16a Fe 0.58/Al 0.42・24d Al 0.63/Fe 0.37。**独立な 2 実装が同じ構造に落ちた**。
- **T3 PbSO4 のセル**: a=8.4821 b=5.3998 c=6.9616 Å (単独)、a=8.4814 b=5.3992 c=6.9610 Å
  (joint)。文献値と一致し GSAS 経路とも同じ解。
- **T4 のセル**: NAC a=10.2516 (初期 10.2512)、CaF2 a=5.4649 (初期 5.4646)。Rwp は未達だが
  格子は妥当な位置に留まっている。

### T3-joint の内訳

X 線 8.26% / 中性子 8.37%。放射源間で偏っていないので、片方だけが壊れている状態ではない。
GSAS との 1.6 ポイント差は残る (未追跡)。

### T4 が未達である理由 (切り分け済み)

内訳は 11BM 25.5% / PG3-1066 45.9% / PG3-2665 48.2% で **TOF 側が支配的**。
放射光の LP 因子を直した時点で 65.8% → 30.9% まで来ており、残りは TOF のピーク形状と
背景項数の詰めと見ている (TOF プロファイルは初期値を相対分解能から置いたのみで、
`tof_profile` 段は本ケースでは revert された)。

## 見つかった実装上の欠陥 (すべて修正済み)

いずれも **「ピークはどこかに立つので tc.exe は正常終了し、Rwp だけが悪い」** 型である。
Rwp を見ても原因に辿り着けないので、当たりを付けて実験で潰すしかない。

| # | 欠陥 | 効果 |
|---|---|---|
| 1 | **特殊位置の座標精度**。TOPAS は多重度を座標の一致 (許容差 ~1e-8) で決めるが、CIF の 5-8 桁では 1/3 が届かず 4f サイトが一般位置 (多重度 12) へ化ける。**単位胞に存在しない原子が 8 個増えたまま完走** (cell_mass 1008.6 → 1329.2) | T1 42.1% → 10.4% |
| 2 | **CW 中性子に Lorentz 因子が無かった**。無いのは*偏光*因子だけ。1/(sin²θcosθ) は 2θ=24° と 158° で 2 桁変わる | T2 12.3% → 5.5%、joint の中性子側 14.4% → 8.4% |
| 3 | **放射光に管球用の偏光項**を当てていた (`LP_Factor(26.4)`)。放射光は散乱面内でほぼ完全偏光 | T4 65.8% → 30.9% |
| 4 | **joint の総合 Rwp が第 1 ヒストグラムのものだった**。`Out(Get(r_wp))` は書かれた `xdd` の値を返す。第 2 ヒストグラムが悪化していても段が受理される | 報告値 8.63 → 実際の総合 10.75 |
| 5 | **`TOF_x_axis_calibration` の引数順**が (difC, difA, Zero) だった。正しくは (Zero, difC, difA) | T4 が回るように |
| 6 | **`x_calculation_step` 未定義/0**。TOPAS の既定も適応式も異常終了しうる | 同上 |
| 7 | **TOF にピーク形状が無かった**、**TOF の Lorentz 因子 d⁴ が無かった** | 同上 |
| 8 | **`reference.io.parse_fxye` が TOF の µs を ÷100 していた** (centidegree 扱い) | 同上 |
| 9 | **多相でのみ落ちる `check_validity` 呼び出し** (相分率を dict で渡していた) | T4 が完走するように |
| 10 | **`Sg/*.sg` のコメント行**を対称操作として読んでいた。体心/面心群の `' +(1/2,1/2,1/2)` はカンマが 2 つある。零行列の偽の操作になり (1/2,1/2,1/2) のサイトの自由軸が消える | 潜在 (座標が解放されない) |
| 11 | **`reference.io` の GSAS STD パーサ**が固定桁 (I2 検出器数 + I6 強度) を空白分割していた。半分の点が 1.0 になる | garnet 99.6% → 16.6% |
| 12 | **占有率の全サイト一斉解放**がスケール因子と大域的に縮退し、Rwp を下げながら占有率を 1 超へ飛ばしていた | T1 の「10.14% で合格」は偽の合格だった |
| 13 | **共有 `prm` が段階解放を無視**していた (TOPAS の名前付き prm は既定で精密化対象) | 段が黙って no-op |
| 14 | **空間群名の `/` は `Sg/` のファイル名で `o` になる** (P63/m → p63om.sg) | 対称操作が引けず座標段が黙って no-op |

## 実行して確かめないと分からなかった TOPAS の仕様

マニュアルは暗号化 PDF でテキスト抽出できないため、言語仕様の正は `topas.inc` と
Tutorial INP と**実行結果**しかない。以下はすべて実測で確定した。

- **tc.exe は構文エラーで異常終了しても終了コード 0 を返す** → stdout マーカー + 出力生成の
  二重の網で判定する。
- サイト併合の許容差は **~1e-8** (分率座標)。3.3e-8 で外れ、3.3e-9 で通る。
- `ZE` マクロ内蔵の箱は **±100 × データ刻み** = 刻み 0.05° なら ±5°。緩すぎてゼロ点が
  +1.16° まで暴走した。
- `TCHZ_Peak_Type` の箱 `min = Max(-1, Val-.1)` は **`Val` を毎回評価する移動する箱**。
  汎用初期値からでも十分遠くまで歩ける (w 0.003 → 0.143)。
- `Cylindrical_I_Correction(=name;)` は `Error loading sstring_in` で異常終了する。
  マクロは自分で `prm` を宣言する形しか通らないので、共有したいなら展開形を書く。
- `out "file"` は `append` を付けない限りファイルを**切り詰めて**開く。xdd ごとに出すと
  joint で 2 本目が 1 本目のレコードを消す。

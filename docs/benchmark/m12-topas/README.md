# M12 ベンチマーク: TOPAS バックエンド vs GSAS-II

同一の実データ・同一の構造ファイルを両エンジンで自動 Rietveld にかけた結果。
**両エンジンが同じ格子・同じ相分率に落ちるか**が最重要の観測点であり、
食い違えばどちらかにバグがある。

測定日: 2026-07-31 / TOPAS 7.0.1.7 (tc.exe) / GSAS-II (ソースツリー)

## 結果

| # | 系 | GSAS-II | TOPAS | 合格基準 | 判定 |
|---|---|---|---|---|---|
| T1 | fluoroapatite 単相ラボ X 線 (P6₃/m) | **9.83%** | **42.1%** | ≤12% | ❌ **未達** (下記) |
| T2 | garnet 単相 CW 中性子 (Ia-3d, Fe/Al 混合占有) | **4.33%** | **11.8%** | ≤6.5% | ❌ 未達 |
| T3 | PbSO4 X 線 (Pnma, 単独ヒストグラム) | 11.0% (joint の X 内訳) | **7.99%** | — | ✅ GSAS を上回る |
| T3-joint | PbSO4 X 線+中性子 joint | 6.66% | 未実施 | ≤8% | ⬜ |
| T4 | NAC+CaF2 TOF+放射光 多相 | ~12.8% | 未実施 | ≤15% | ⬜ |

T3 (PbSO4 単独 X 線) の精密化セル **a=8.4820 b=5.3998 c=6.9616 Å** は文献値と一致し、
GSAS 経路と同じ解に落ちている。

## T1/T2 が未達である理由 (切り分け済み)

**構造ファイルは正しい**: GSAS-II に同じ `FAP.cif` を渡すと **Rwp 9.80%** (原本 `FAP.EXP` の
9.806% と一致)。したがって CIF 化は忠実で、差は TOPAS 経路の側にある。

`Out_X_Yobs_Ycalc` で計算パターンを実測すると、**ピーク位置はほぼ一致するのに相対強度が誤って
いる**:

| | 上位ピーク 2θ |
|---|---|
| 観測 | 25.80, 29.04, **31.86**, 33.04, 34.08, 39.98, 46.82, 49.52 |
| 計算 | **18.94**, **21.90**, 28.14, 29.10, 32.26, 33.10, 34.14, 46.88 |

計算では (110) 18.94° と (200) 21.90° が強く出るが観測には無く、観測で最強の (211) 31.86° と
(002) 25.80° が計算で弱い。つまり**構造因子の計算が食い違っている**。

除外できた原因:

- **発光プロファイル**: 自作 `lam` ブロックを公式 `CuKa5(0.001)` マクロに差し替えても同じ (60.2 vs 60.3)。
- **初期ピーク幅**: TCHZ の初期 w を 0.003 / 0.01 / 0.02 と振っても Rwp は 42.07 → 42.00 とほぼ不変。
- **CIF の座標精度**: 5 桁 → 8 桁にしても不変。
- **対称操作**: 自由軸判定は 4f (CA1: z のみ) / 6h (CA2: x,y) / 2a (F4: 固定) を正しく識別している。

**直方晶 PbSO4 は 7.99% で正常**なので、六方晶 (および立方晶 garnet) 固有の問題である疑いが濃い。
次に確認すべきは **TOPAS のサイト多重度の解釈と `occ` の意味論** (占有率を全解放したときに
CA1 → 0.68 / 他 → 2.0-2.24 という「多重度がずれた」ような値へ落ちる)。

## 併せて判明した実装上の欠陥 (すべて修正済み)

1. **`reference.io` の GSAS STD パーサ**が固定桁 (I2 検出器数 + I6 強度) を空白分割していた。
   半分の点が 1.0 になる。M7 の GSAS 経路は GSAS-II が .raw を直接読むため露見していなかった。
   garnet で **Rwp 99.6% → 16.6%**。
2. **占有率の全サイト一斉解放**がスケール因子と大域的に縮退し、Rwp を下げながら占有率を
   1 超へ飛ばしていた (fluoroapatite で 0.68-2.24)。**T1 の「Rwp 10.14% で合格」は偽の合格**だった。
3. **共有 `prm` が段階解放を無視**していた (TOPAS の名前付き prm は既定で精密化対象)。
4. **空間群名の `/` は `Sg/` のファイル名で `o` になる** (P63/m → p63om.sg)。知らないと
   `/` を含む空間群で対称操作が引けず座標段が黙って no-op になる。

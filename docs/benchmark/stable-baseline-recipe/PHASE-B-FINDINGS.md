# Phase B 実測: 初期値摂動による収束確認 (2026-07-30)

**問い**: Phase A で選んだ手順を固定したまま初期値を振ると、同じ解へ戻ってくるか。

**条件**: 格子 ±0.7% の決定論グリッド 5 開始点 + 座標ジッタ (対称性が自由な軸のみ)。
BLAS は 1 スレッドに固定 (親で設定し子が継承)。判定は構造 (格子・座標・占有率) と歪
(サイズ/微小歪み) の一致で、装置プロファイルは最良フィット選択に委ねる。

## 2. 読み取れること

### 2.1 ★ 両データとも収束確認に通らない。**ただし壊れ方が違う**

| | 分岐しているもの | Rwp のばらつき | 意味 |
|---|---|---|---|
| **T1** | **歪** (サイズ/微小歪み) | **9〜12** ポイント | 当てはめの質そのものが開始点で大きく違う |
| **T3** | **格子** | **0.1** ポイント | ほぼ同じ当てはめなのに格子が違う = 目的関数が平坦 |

同じ「非収束」でも処方が違う。T1 は**縮退の解消** (下記 2.2)、T3 は**格子を決める情報が
足りない** (既知の REQ-SAR-501 順序依存と同じ現象) が対処になる。

### 2.2 ★ T1 の歪の分岐は「悪い局所解」であって微妙な差ではない

同一条件の 3 開始点で:

| start | Rwp | サイズ (µm) | 微小歪み |
|---|---|---|---|
| 0 | 12.54 | 0.176 (esd 0.0020) | 229 (esd 24) |
| 1 | **9.67** | 0.284 (esd 0.0089) | 572 (esd 42) |
| 2 | 19.59 | **0.0010** (esd なし) | 1447 (esd 25) |

start2 は結晶子サイズ **1 nm** へ潰れている。鋭いピークを与える試料としてあり得ず、極端な
広がりでピーク形状を代償している。サイズと微小歪みと Caglioti U/V/W は**どれもピーク幅を
支配する**ので縮退しており、片方が振れればもう片方が代償する。これは Issue #38
(装置分解能の抽出・固定) が解こうとしている問題そのもので、収束確認によって可視化された。

### 2.3 ⚠ `check_validity` は結晶子サイズの潰れを検出しない

上の start2 (**1 nm**) を含め、T1 は全開始点が **validity pass** だった。
`validity.py` にサイズ/微小歪みへの言及は**ゼロ**である。物理妥当性ゲートが素通りさせるため、
明らかに壊れた開始点が「valid」として数えられ**ベイスン数を水増しする**。

⚠ 本キャンペーンでは**修正していない** — 全ベンチマークの validity 判定に影響するため、
既定を動かす変更は独立した測定とセットで行うべきである。Issue 化を推奨。

### 2.4 座標は両データとも頑健

0.10 Å 動かしても座標クラスは**常に AGREE** (T1 60 軸 / T3 55 軸を実際に動かした上で)。
発散も validity fail の増加も無い。**判定を分けているのは座標ではない。**

## 3. 座標摂動の既定量: **0.05 Å**

判断材料は「構造ベイスンを実際に探れているか」と「大きすぎて壊れないか」。掃引の結果:

- 壊れる上限は **0.10 Å より上**にある (この 2 データでは無傷)。
- 0.05 と 0.10 で**情報量は変わらなかった** (どちらも座標 AGREE・判定は他クラスが決める)。

そこで**一致判定の床 (0.02 Å) の 2.5 倍**を採る。「許容差より大きく動かして、許容差の内側へ
戻ってきた」と言える最小の振幅であり、出発構造として物理的にも無理がない。上限側の余裕は
残す — 軽原子や短い結合を持つ構造では 0.10 Å が隣接サイトへ踏み込み得るので、**2 データの
無傷をもって安全とは言えない**。

## 4. 並列の実効

BLAS を両方 1 スレッドに固定した公平な比較 (T1, 3 開始点): 直列 294.9s → 並列 222.0s
(**1.33×**)。3× にならないのは**律速が最も遅い開始点**だから — 摂動された開始点は無摂動より
5 倍近く長くかかる (悪い基底から抜け出そうとして反復が伸びる)。「壁時計 ≈ 1 開始点分」は
正しいが、その 1 開始点は**平均ではなく最悪**である。

## 5. 積み残し

1. **T1 の歪の縮退** — `instrument_profile` (Issue #38) で装置分解能を固定した条件で
   収束確認をやり直す。縮退が解ければ歪は決まるはず。
2. **`check_validity` にサイズ/微小歪みの物理性検査が無い** (§2.3)。
3. **T3 の格子の平坦さ** — Rwp 0.1 ポイントの差で格子が割れる。追加測定 (OED) か
   格子を決める情報 (高角側/別波長) の検討。
4. **多相/TOF は依然として範囲外** (T4 除外の継続)。

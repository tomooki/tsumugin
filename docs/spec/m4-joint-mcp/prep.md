# m4-joint-mcp 準備タスク（ユーザー作業）

> **仕様**: [requirements.md](requirements.md) / **生成日**: 2026-07-04

**【信頼性レベル凡例】**: 🔵 明確に必要 / 🟡 妥当な推測 / 🔴 予防的推測

## 必須（実装開始前に完了が必要）

なし — M4 も外部サービス・認証情報・追加インフラを必要としない。
テストは合成データで完結し、xraylib / .mpr / MEM (Dysnomia) は実装せず境界のみ。
MCP SDK は optional extra とし、未導入環境でもツール実処理関数は動作する。

## 推奨（実装中に用意できればOK）

- [ ] **中性子テストデータ (検証用, 任意)** 🟡 *仕様 §12-6 joint ベンチより*
  - 既知系 (例: Ni/Fe/Mn 系電極) の X線 + 中性子ヒストグラム 1 セットがあると M4 完了後の
    実地検証 (占有率精度向上の定量) に使える。M4 のテスト自体には不要 (合成データで完結)
  - 関連要件: REQ-005, REQ-010

## 確認事項（判断が必要）

- [ ] **MCP SDK (`mcp` パッケージ) を optional extra として追加する方針の可否** 🟡 *interview Q9/REQ-102*
  - M4 は `[project.optional-dependencies] mcp = ["mcp>=1.0"]` を追加し `uv sync --extra mcp` で導入する想定。
    未導入環境では MCP サーバ起動のみ friendly error に縮退し、ツール実処理関数は通常テストで網羅する
  - 関連要件: REQ-021, REQ-022, REQ-102, REQ-403
- [ ] **中性子散乱長 b の静的テーブルの範囲 (対象元素) の確認** 🟡 *interview Q5/REQ-010*
  - v1 は元素代表値の軽量テーブルで足る (同位体別精密値・xraylib は M-later)。
    対象元素を M4 テスト系 (Ni/Fe/Mn 等) に必要な範囲へ限定してよいか
  - 関連要件: REQ-010, REQ-403
- [ ] **MCP Server のトランスポート/バインド既定 (stdio / 127.0.0.1) の確認** 🟡 *interview Q12/REQ-405*
  - 既定はローカル・無認証ネットワーク公開はしない。公開時認証は M4 スコープ外
  - 関連要件: REQ-303, REQ-405

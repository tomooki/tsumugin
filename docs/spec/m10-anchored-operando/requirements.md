# M10 アンカー基準双方向 operando 逐次解析 要件定義 (EARS)

対象: `tsumugin.insitu.anchor` (新規サブモジュール) + `autorietveld.validity` 拡張 (結合距離/配位数) +
`insitu.model` 拡張 (AnchorConfig)。仕様書 (正) `docs/tsumugin_spec_v0.3.md` **FR-330 (331〜338)** に対応。
BIC は既存 `operando/segmentation.py:_frame_bic` / `nested/laplace.py:_bic_value` を再利用。

## 0. 背景 — 現行 forward-only の限界

M9 `run_sequential_rietveld` は frame 0 起点の**前方単一パス** warm-start。転移域では少数相 (delta) の
異方格子誤差 (DFT 由来, c 軸 +3.4%) を warm-start が飛び越えられず Rwp 高止まり → 偽相を誘発する
(実測)。`_consolidate_phase_cells` (支配フレームのセルを事後配布) は後付けパッチ。**アンカー基準双方向**は
これを原理的に一般化する: 最も信頼できるフレームから両側へ詰め、区間ごとに IC で最良経路を選ぶ。

## 1. ユーザーストーリー

- 研究者として、転移域を含む operando/高温系列で、**初期フレームの良否に依存せず**、信頼できる相領域を
  起点に相転移を頑健に追跡してほしい。
- 各フレームを両方向から解析し、**統計的に妥当な (過剰適合でない) 相集合**と単調な相分率転移を得たい。
- 誤構造が偶然 Rwp に合う場合を、**結合距離・配位数**の物理チェックで弾いてほしい。
- 判断 (アンカー確定・crossover 選定) は非破壊・提案≠適用で、根拠 (bic 差・妥当性) を追跡したい。

## 2. 機能要件 (EARS)

### 2.1 アンカー抽出 (FR-331)
- **REQ-1001** `extract_anchors` は、各フレームの相同定信頼度 (Dara スコア・スコアマージン top1−top2・
  strain・未知相フラグの合成) が `anchor_confidence_min` 以上のフレームを**アンカー候補**とせねばならない。
- **REQ-1002** システムは、アンカー候補を実構造 Rietveld で精密化し、**Rwp ≤ `anchor_rwp_max` ∧
  物理妥当性 pass** を満たす候補のみ**確定アンカー**とせねばならない (2 段ゲート)。
- **REQ-1003** システムは、確定アンカーが 0 個のとき、`anchor_rwp_max` を満たす**最小 Rwp フレーム 1 個**を
  fallback アンカーとし、単一パス (M9 相当) に縮退せねばならない (常に解析可能)。
- **WHERE** 相同定が無効 (`phase_id=None`) のとき、システムは frame 0 を単一 fallback アンカーとし、M9
  forward-only と等価に振る舞わねばならない (後方互換)。

### 2.2 アンカー精密化と区間構成 (FR-332/333)
- **REQ-1004** システムは、確定アンカーを Rwp 昇順でなく**フレーム順**に整列し、隣接対 `[L, R]` の区間列
  (端点前後の片側区間を含む) を構成せねばならない。
- **REQ-1005** `refine_segment_forward` は、区間 `[L, R]` の内側フレームを **L の相集合と精密化格子で
  warm-start し前方 (L→R) 逐次**精密化せねばならない。
- **REQ-1006** `refine_segment_backward` は、同区間を **R の相集合と精密化格子で warm-start し後方 (R→L)
  逐次**精密化せねばならない。
- **REQ-1007** システムは、前方/後方パスを相互独立に実行し (共有状態なし)、各フレームが**2 回**精密化
  される結果を保持せねばならない。**WHERE** 並列 executor 未指定なら逐次実行でよい (結果は同一)。
- **REQ-1008** システムは、いずれかの端点区間 (最初のアンカー以前・最後のアンカー以降) を**片方向のみ**で
  解析せねばならない (bracket が片側のみ)。

### 2.3 モデル選択による経路選定 (FR-334)
- **REQ-1009** `select_crossover` は、区間の前方/後方フィット列に対し、**相集合が異なるフレームでは
  IC (bic) で比較**せねばならない (Rwp 生値は相数増加で単調減少し不公平なため)。
- **REQ-1010** システムは、区間 `[L, R]` に対し「L..k は前方採用・k+1..R は後方採用」の **crossover 点 k を
  区間総 bic 最小で選定**せねばならない (全 k を評価する O(区間長) スキャン)。
- **REQ-1011** システムは、選定経路の**相分率が転移方向に単調**になる crossover を優先せねばならない
  (同 bic 内では単調性を tie-break に用いる)。
- **WHERE** 前方/後方が**同一相集合**の区間では、システムは bic の代わりに Rwp (or gof) 最小で
  フレーム毎に選んでよい (パラメータ数が同一なら Rwp 比較は公平)。

### 2.4 物理妥当性ゲート (FR-335)
- **REQ-1012** `check_bond_validity` は、精密化構造の**最近接結合距離**が元素対の共有結合半径和の
  `bond_tol_lo`〜`bond_tol_hi` 倍に収まるか、および**配位数**が期待範囲かを検査せねばならない
  (pymatgen `CrystalNN`/近接解析, 遅延 import)。
- **REQ-1013** システムは、crossover 選定で bic 同点・僅差のとき、**物理妥当性 (結合距離/配位数) pass**を
  採用条件に加えねばならない (誤構造の偶然フィット棄却)。
- **WHERE** pymatgen 不在のとき、システムは結合距離/配位数チェックを**スキップ**し bic + 既存 validity
  のみで選定せねばならない (gate, クラッシュさせない)。

### 2.5 転移 onset と出力 (FR-336/337)
- **REQ-1014** システムは、crossover 点が**相集合変化 (新相 birth) を含む区間**のとき、その crossover
  フレームを転移 onset として `PhaseAppearance` に記録せねばならない (FR-323 と整合)。
- **REQ-1015** システムは、相の birth/death を**ヒステリシス**で判定し、単一フレームの点滅を抑制
  せねばならない (相分率が連続 `hysteresis_frames` フレームで `frac_min` 未満なら death)。
- **REQ-1016** システムは、前方/後方の両トライアルと選定理由 (crossover k・区間総 bic 前後・妥当性) を
  **ledger に追記**し、採用経路を記録せねばならない (棄却経路も保持, P2)。
- **REQ-1017** `run_anchored_sequential` は、組み立てた採用フレーム列・アンカー・appearances・ledger を
  `SequentialRietveldResult` (既存型) 互換で返さねばならない (下流のパラメトリック解析が再利用可)。

### 2.6 非破壊・決定論 (FR-337/338, P2/NFR-102)
- **REQ-1018** システムは、生データ・ledger の削除/上書き API を持たず、全状態変更を追記 + 採用経路の
  選択で表現せねばならない (P2)。
- **REQ-1019** システムは、双方向パスと crossover 選定に乱数を用いず、同一入力で**ビット同一の採用経路**を
  返さねばならない。アンカー端点マルチスタートの摂動種は固定せねばならない (NFR-102)。

## 3. 非機能要件

- **NFR-M10-1** コアオーケストレーション (アンカー抽出・区間構成・crossover 選定・bic) は **numpy-only**。
  GSAS (精密化) は注入 runner 経由、pymatgen (結合距離/配位数) は遅延 import に隔離する。
- **NFR-M10-2** テストは実装ファイルと 1:1。GSAS/pymatgen 非依存の決定論部 (アンカー選定ロジック・
  crossover 選定・bic 比較) は stub runner で green。実データ検証は `@pytest.mark.gsas`。
- **NFR-M10-3** 計算コストは全フレーム約 2 回精密化 + アンカー精密化 (≈2N)。区間独立で並列化余地を残す
  (本 M10 は逐次実装で可、並列 executor は M-later)。

## 4. スコープ外 (M-later)

- 区間並列実行の executor (本 M10 は決定論逐次で実装, 結果は並列と同一)。
- アンカー端点マルチスタートの座標摂動 (格子摂動のみ, `multistart` 既存に準拠)。
- 3 相以上同時 crossover / 非単調転移 (往復反応) の一般化。
- JMAK 等の反応速度論フィット (FR-324, 外部委譲)。

## 5. 受け入れ基準 (検証データ)

- **AC-1** CaTeO3 cyclic (14 フレーム, alpha·H₂O→delta 転移): alpha 単相域と delta 支配域がアンカーに
  なり、転移 (frame 120–210) を双方向で詰め、**crossover で onset を確定**。現行 forward+consolidate より
  転移域 Rwp が低く、偽相 (Ca3TeO6 等) が出ないこと。
- **AC-2** 決定論: 同一入力で採用経路がビット同一 (NFR-102)。
- **AC-3** 単相系列 (新相なし) では全フレームが 1 アンカー区間に入り M9 単一パスと同等の結果に縮退。

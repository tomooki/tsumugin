## エピック1: 非物理プロファイルの自動 revert

### ストーリー 1.1: 幅関数が非物理化した段階を自動 revert する 🔵

**信頼性**: 🔵 *ユーザ入力設計(2)(3)*

**私は** 自動 Rietveld を回すエージェント **として**
**プロファイル解放段階でガウス/ローレンツ幅やTOF分散が測定レンジ内で負に振れたとき、その段階を revert したい**
**そうすることで** Rwp が偶々下がっても非物理な幅で「フィットできたつもり」になるのを防げる

**関連要件**: REQ-002, REQ-003, REQ-005, REQ-101, REQ-201

**詳細シナリオ**:
1. 段階が `profile` (U,V,W) を解放し精密化する。
2. 精密化後、`H_G² = U·tan²θ + V·tanθ + W` を測定レンジ端点＋頂点で評価。
3. どこかで ≤ 0 なら `_profiles_physical` が False → `rwp=gof=inf` → 既存 revert 経路で直前段階へ復元。

**前提条件**: engine が段階解放ループを回している。
**制約事項**: accept/revert の基本構造は不変 (`_cells_physical` と同格の 1 ガード追加)。
**優先度**: Must Have

### ストーリー 1.2: TOF の立上り/減衰係数がゼロ以下に走ったら revert する 🔵

**信頼性**: 🔵 *ユーザ入力設計(2)/T4 教訓 (1/alpha,1/beta 発散)*

**私は** TOF 中性子を含む joint 解析を回すエージェント **として**
**alpha / beta が 0 以下に走った段階を revert したい**
**そうすることで** `1/alpha`,`1/beta` の発散による破綻を未然に防げる

**関連要件**: REQ-006, REQ-101, REQ-201
**優先度**: Must Have

---

### ストーリー 1.3: 未解放パラメータの初期値で誤 revert しない 🔵

**信頼性**: 🔵 *ユーザ入力設計(2) 誤revert防止*

**私は** 装置由来の近似 instprm を使うエージェント **として**
**まだ解放していないパラメータの borderline な初期値を理由に段階が revert されたくない**
**そうすることで** 健全な段階が初期値のせいで無駄に巻き戻るのを防げる

**関連要件**: REQ-102
**詳細シナリオ**:
1. `X` が未解放 (refined=False) で初期値が僅かに負。
2. 個別係数の符号違反は revert 判定に用いない → 段階は維持される。

**優先度**: Must Have

## エピック2: 内省と診断連携

### ストーリー 2.1: 精密化後のプロファイル値を結果から読める 🔵

**信頼性**: 🔵 *ユーザ入力設計(1)*

**私は** 解析結果を評価するエージェント/人間 **として**
**AutoRietveldResult から各ヒストグラムの精密化後プロファイル値を読みたい**
**そうすることで** どの装置パラメータがどう動いたかを事後検証でき、診断 (`diagnose_residual`) も実値を使える

**関連要件**: REQ-001, REQ-403 (連携)
**優先度**: Must Have

---

### ストーリー 2.2: 過大値は revert せず警告で残す 🔵

**信頼性**: 🔵 *ユーザ入力設計(4) 第2層*

**私は** 解析の質を後で吟味する人間 **として**
**hard 物理制約は満たすが soft 上限 (過大な SH/L 等) を超えた場合は、revert でなく警告として残してほしい**
**そうすることで** 収束は止めずに「要注意」を把握できる

**関連要件**: REQ-103
**優先度**: Should Have

# M7 実データ検証 (自動 Rietveld 解析) 要件定義書

## 概要

GSAS-II 公式チュートリアル (Rietveld refinement セクション) の実データ4例を tsumugin の
自動解析で解析し、チュートリアル同等の Rwp/GOF/物理的妥当性を達成する。検証を通じて自動解析
アルゴリズム (段階解放レシピ・ガードレール・物理妥当性ゲート) を洗練させ、AI エージェントが
指示書のみで同等解析を再現できる状態を作る。

現行 `GSASIIBackend` は M0/M1 の格子同定用に **P m m m + Ni ダミー構造**で `scale`/`lattice.*`
のみを精密化する。M7 では **実 CIF 構造**での本格 Rietveld 精密化 (背景・試料変位・プロファイル・
原子座標・Uiso・占有率・制約) を新設し、実データで検証する。

## 機能要件 (EARS 記法)

### 通常要件

- REQ-001: システムは、データファイル・装置パラメータファイル・相構造 (CIF もしくは GSAS .EXP)
  を入力として GSAS-II プロジェクトを構築し、実構造 Rietveld 精密化を実行しなければならない
  🔵 *PLAN §3 中核ギャップ・GSASIIscriptable API*
- REQ-002: システムは、段階解放レシピ (scale+背景 → 格子+試料変位/ゼロ → プロファイル UVW →
  原子座標 → Uiso → 占有率) に従って自動で段階的にパラメータを解放しなければならない
  🔵 *チュートリアル T1–T4 手順の一般化 (PLAN §4)*
- REQ-003: システムは、各段階の後に Rwp・GOF・精密化パラメータ・共分散を記録しなければならない
  🔵 *既存 RefinementReport / ledger*
- REQ-004: システムは、精密化結果に対し物理的妥当性 (格子定数の妥当範囲・Uiso>0 かつ上限内・
  占有率∈[0,1]・制約充足) を判定し妥当性レポートを返さなければならない 🔵 *達成目標*
- REQ-005: システムは、実験室 X 線 (CuKα)・CW 中性子・TOF 中性子・放射光 の各放射源/幾何を
  区別し、適切な既定 (背景関数・変位パラメータ種別) を選択しなければならない 🔵 *T1–T4 の幾何差*

### 条件付き要件

- REQ-101: ジオメトリが Bragg-Brentano の場合、システムは試料変位 (sample displacement) を
  解放し、ゼロシフトより優先しなければならない 🔵 *T1 LabData 手順*
- REQ-102: 混合占有サイト (例 Fe/Al) を含む相の場合、システムは占有率等価制約と占有率和制約を
  自動生成できなければならない 🔵 *T2 CWNeutron 手順*
- REQ-103: 複数ヒストグラムが異なる測定温度の場合、システムは格子を共有しつつ per-histogram の
  静水圧歪み (Dij) で格子差を吸収しなければならない 🔵 *T3/T4 手順*
- REQ-104: 多相精密化の場合、システムは各ヒストグラムで相分率和=1 の制約を自動生成しなければ
  ならない 🔵 *T4 TOF-CW 手順*
- REQ-105: ある段階で Rwp が悪化した場合、システムは直前スナップショットへ revert し当該段階の
  パラメータなしで継続しなければならない (既存 FR-202 を実構造精密化にも適用) 🔵 *既存ガードレール*

### 状態要件

- REQ-201: 背景残差が大きい状態の場合、システムは背景項数を動的に増やしてよい (初期 3 項)
  🔵 *T4 手順 (背景 3→6)*

### 制約要件

- REQ-401: システムは、GSAS-II を遅延 import に隔離し、コア import は numpy のみを維持しなければ
  ならない (GSAS-II 依存テストは `@pytest.mark.gsas`) 🔵 *CLAUDE.md 不変条件*
- REQ-402: システムは、乱数種を固定し再現性 (NFR-102) を保たなければならない 🔵 *CLAUDE.md*
- REQ-403: システムは、精密化バックエンドの失敗を例外でなく chi2=inf の結果に変換し、
  ガードレールに処理させなければならない 🔵 *CLAUDE.md 不変条件*
- REQ-404: システムは、Ledger の追記専用・ハッシュチェーン (NFR-105) を維持しなければならない
  🔵 *CLAUDE.md*
- REQ-405: FXYE (ESD 列)・TOF (.gsa) データと `.instprm` を読み込めなければならない (T4 に必要)
  🔵 *PLAN §3 ローダーギャップ*

## 非機能要件

### パフォーマンス

- NFR-001: 単相単一ヒストグラム自動解析は妥当時間内 (数分オーダー) で完了すること 🟡 *推測*

### 検証精度 (達成目標)

- NFR-101: T1 fluoroapatite で Rwp ≤ 12%, GOF ≤ 4.5 (チュートリアル 10.38%/3.44) 🔵 *PLAN §2*
- NFR-102: T2 garnet で Rwp ≤ 6.5%, 占有率制約充足 (チュートリアル 5.18%) 🔵 *PLAN §2*
- NFR-103: T3 PbSO4 joint で合計 wR ≤ 8% (チュートリアル 6.71%) 🔵 *PLAN §2*
- NFR-104: T4 NAC+CaF2 で Rw ≤ 8.5%, 相分率制約充足 (チュートリアル 6.83%) 🔵 *PLAN §2*

### 成果物

- NFR-201: 改良された自動解析アルゴリズム (モジュール + 回帰ベンチ) 🔵 *タスク成果物*
- NFR-202: AI エージェント自動解析指示書 `AGENT_PLAYBOOK.md` — エージェントが指示書のみで
  T1–T4 相当を再現できること 🔵 *タスク成果物*

## Edge ケース

- EDGE-001: 相構造 CIF が装置波長と大きくずれた格子を持つ場合、格子精密化前に発散し得る →
  段階解放は cell を早期に解放し、Rwp 悪化時 revert で保護する 🟡 *既存 align_peaks 教訓*
- EDGE-002: 中性子データで負の散乱長を持つ元素 (例 H, Mn) → 前方計算で符号を正しく扱う (GSAS-II
  が処理) 🟡 *推測*
- EDGE-003: TOF データの複数バンク/フレーム (POWGEN 1.066Å/2.665Å) → フレーム毎に instprm を
  対応付ける 🔵 *T4 手順*
- EDGE-004: 精密化が非収束 (max cyc 到達) → converged=False を記録し妥当性レポートに反映 🔵

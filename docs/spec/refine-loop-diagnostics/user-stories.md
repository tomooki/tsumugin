## エピック1: 残差から次手を「見える」化する (前提工事)

### ストーリー 1.1: 精密化結果の内省 🔵

**信頼性**: 🔵 *GAP 前提工事1*

**私は** 自動解析エージェント **として**
**精密化結果から per-atom の Uiso/占有率・per-hist の吸収/プロファイル値・obs/calc の幅/非対称/
配向指標を読み取りたい**
**そうすることで** 幅・非対称・PO・Uiso・吸収の異常を診断できる(現状は残差配列と cell しか見えない)。

**関連要件**: REQ-001
**優先度**: Must Have

### ストーリー 1.2: 残差解析による診断シグネチャ算出 🔵

**信頼性**: 🔵 *GAP 前提工事2*

**私は** 自動解析エージェント **として**
**残差配列と内省フィールドから診断シグナル(幅比/非対称/位置/PO/背景 overfit/Uiso 発散/吸収不確実)を
算出したい**
**そうすることで** 背景のみの粗診断を脱し、多様な系統誤差にトリガをかけられる。

**関連要件**: REQ-002
**優先度**: Must Have

## エピック2: 候補を別々に試して観察する (診断オートトライ)

### ストーリー 2.1: 非対称/位置を別々に解放 🔵

**信頼性**: 🔵 *serious-flow §6・核心原理*

**私は** 自動解析エージェント **として**
**非対称残差を見たら、シフト(Zero)と非対称(SH/L・alpha/beta)を別々の候補として試したい**
**そうすることで** 「どちらが効くか」を焼き込まず try→revert で判定できる(材料固有結論を排する)。

**関連要件**: REQ-101, REQ-003
**優先度**: Must Have

### ストーリー 2.2: 選択配向・幅・背景の診断 🔵

**信頼性**: 🔵 *serious-flow §6・GAP 表B*

**私は** 自動解析エージェント **として**
**系統的 obs>calc なら選択配向、幅ずれなら U,V,W/X,Y/size を別々に、背景 wiggle 過剰なら減項を
提案したい**
**そうすることで** プロファイル/配向/背景の系統誤差を自律的に詰められる。

**関連要件**: REQ-102, REQ-103, REQ-104
**優先度**: Must Have

### ストーリー 2.3: 限定/値固定アクション 🔵

**信頼性**: 🔵 *GAP 表B/C P2*

**私は** 自動解析エージェント **として**
**Uiso 発散なら解放対象を重原子/水に限定(RestrictUiso)、吸収不確実なら free/物理/0 を試す
(SetAbsorption)ようにしたい**
**そうすることで** 「解放」では表せない限定/値固定の手も自律トライできる。

**関連要件**: REQ-105, REQ-106, REQ-004
**優先度**: Must Have

## エピック3: モデルを裁定する (第3層)

### ストーリー 3.1: BIC+妥当性でモデル変種を裁定 🔵

**信頼性**: 🔵 *ヒアリング P4*

**私は** 結晶学者/エージェント **として**
**構造モデル変種(水の要否・吸収 on/off 等)を精密化し BIC+物理妥当性で序列化したい**
**そうすることで** 単一モデルの追い込みでは決まらないモデル選択を客観的に裁定できる。

**関連要件**: REQ-005, REQ-202
**優先度**: Must Have

# 電気化学制約付き operando Rietveld — 要件定義 (FR-318)

充放電の反応電気量 (クーロメトリー) を可動アルカリ量の独立測定として operando Rietveld に
接続する。制約 (占有率固定・restraint・相分率拘束) と診断 (XRD vs echem 乖離) の両方を提供する。

- 系譜: FR-311 (容量→組成x換算, `operando.echem`) を精密化へ配線 / FR-213 (組成拘束テンプレート) の
  実体化 / Issue #103 (echem ② 露出) の後続。
- ユーザー確定判断: (1) Na/K ハイブリッド系では**総アルカリ (Na+K 和)** を拘束
  (電子数 = 総アルカリ挿入量が化学的に厳密。Na/K 分配は XRD 側精密化)。
  (2) **既定モードは diagnose**。完全拘束 (lock_fractions) は明示 opt-in で第3層判断。

## 用語

| 記号 | 意味 |
|---|---|
| Q(t) | 実測積算電気量 [mAh] (`EchemCurve.charge_mah`, CC/CV/rest 全対応) |
| n_e(t) | 式単位あたり反応電子数 = Q/m_active × M / 26801.5 / z |
| x_total(t) | 電極全体の式単位あたり可動アルカリ量 = x₀ − sign·n_e(t) |
| x_i | 相 i の式単位あたりアルカリ量 = Σ_sites Σ_species occ·mult / Z_i |
| x_XRD | XRD 由来のモル平均 = Σ φᵢᵐᵒˡ·x_i, φᵢᵐᵒˡ = (wᵢ/FWᵢ)/Σ(wⱼ/FWⱼ) |

## 機能要件 (EARS)

### REQ-318-001 電気量→電子数変換 (ユーザー要件1)
- システムは、活物質質量 m_active と式量 M (とイオン価数 z, 既定 1) を引数として受け取り、
  実測積算電気量 Q(t) [mAh] を式単位あたり反応電子数 n_e(t) に変換しなければならない。
- 変換は F = 26801.5 mAh/mol (= 96485 C/mol ÷ 3.6) を用いること。
- 通常時、線形性 (CC 仮定) に依存せず**実測 Q(t)** を用いること (CV 保持・rest を正しく扱う)。

### REQ-318-002 初期組成 (ユーザー要件2, 3)
- 初期組成 x₀ が与えられた場合、システムは対応する占有率を**凍結** (精密化フラグ off) して
  Rietveld 解析を行わなければならない (fix モード)。
- x₀ が与えられなかった場合、システムは占有率を精密化して x₀ を算出しなければならない。
  精密化スコープは選択可能であること:
  (a) フレームワーク固定・可動イオン占有率のみ (`free_occupancy_labels` 既存機構) /
  (b) フレームワークも精密化。**スコープの選択は第3層の判断事項** (③ skill に判断基準を記載)。
- x₀ の由来 (given / first_frame / anchor) を結果に記録すること。

### REQ-318-003 フレーム同期と目標量 (ユーザー要件4)
- システムは既存 `align_frames` (時刻同期) により XRD フレームと echem 点を対応付け、
  各フレームの x_total(t) = x₀ − sign·n_e(t) を算出しなければならない。
- sign (充電で正極アルカリ減 = +1 相当) は明示引数とし、`FramePoint.state` (charge/discharge)
  と自動照合して矛盾時に警告しなければならない (配線ミス・電極取り違え検出)。
- `in_span=False` のフレームには制約を適用してはならない (echem 範囲外の捏造禁止)。
  `state=rest` は Q 一定なので適用可。
- 多相の場合、拘束量は**各相の合計** (モル平均 x_XRD) であること。

### REQ-318-004 多相での拘束 (ユーザー要件5)
- 2 相以上の場合、各相の x_i は単相領域 (アンカー) の精密化結果に固定し、
  総アルカリ量制約下で相分率を精密化できなければならない (lock_fractions モード)。
- lock_fractions は Scale について線形な制約 `Σ Scaleᵢ·Zᵢ·(xᵢ − x_total) = 0` で実装する。
- **注意**: 2 相では Σφ=1 と合わせ相分率が完全決定され、XRD は相分率に寄与しなくなる
  (Rwp が一致度の検定量になる)。この旨を警告し、**既定にはしない** (明示 opt-in・第3層判断)。
- 実行可能性ゲート: x_total ∉ [min xᵢ, max xᵢ] のフレームは拘束不能 → 拘束せず diagnose に
  縮退し警告すること (= 多相域の不可逆容量検出器)。フレーム毎に評価する。
- xᵢ が相間で (許容差内で) 等しい場合、制約は和制約と縮退するため skip すること。

### REQ-318-005 U/B の扱い (ユーザー要件6)
- 組成導出に関与する精密化では Uiso/B は原則精密化せず、妥当値・初期値に固定すること。
- 初期 Uiso が妥当帯 (既定 [1e-3, 0.05] Å²、可動イオンは上限緩和可) を外れる場合、
  **精密化前に**警告を出さなければならない。
- 占有率精密化と Uiso 精密化が同時に指定された場合 (縮退により導出組成が汚染される)、
  警告を出さなければならない。

### REQ-318-006 アンカー A/B 検証 (ユーザー要件7)
- 単相アンカーにおいて、システムはアルカリ量制約の**有り・無し 2 通り**の精密化を実施し、
  ΔRwp が閾値を超える場合に警告を出さなければならない (不可逆容量の疑い)。
- その場合、精密化結果のアルカリ量による x₀ 校正を**提案**しなければならない。
  提案≠適用 — 採用判断は第3層へ移譲する (P2 非破壊、ledger 記録)。

### REQ-318-007 診断出力 (要件8 拡張)
- diagnose モード (既定) では、毎フレーム x_XRD ± esd と x_echem、乖離 (coulometric_residual)、
  制約適用有無、実行可能性を結果に含めること。
- x_XRD のモル平均換算は**重量分率を式量 FWᵢ で割る** (セル質量 Zᵢ·FWᵢ で割ると Z 二重計上)。
  esd は σ²(x_XRD) = Σ (∂x_XRD/∂wᵢ)²σ²(wᵢ) (+占有率 esd 項) で伝播する。
- 相分率が auto_freeze 閾値以下の相の xᵢ 出力には品質フラグを付すこと。

### REQ-318-008 複数元素サイト (Na/K)
- 可動イオンサイトは**複数元素 (例 Na+K) の占有率合算**に対応しなければならない。
  拘束は合算量 (occ_Na + occ_K の mult 重み付き和) に適用する。
- mult (サイト多重度) と Z (セルあたり式単位数) は GSAS 原子行から自動抽出し、
  呼び出し側指定値と照合して不一致時に警告すること。

### REQ-318-009 ②③ 露出 (★不変条件)
- 同一 PR で ② MCP ツール (`alkali_budget` + `sequential_rietveld`/`anchored_sequential` の
  `charge_constraint` spec) と ③ skill 手順書 (insitu + operando-diagnose + 両 PLAYBOOK) を追加すること。
- ② ツールは例外を送出せず `{"error","error_type"}` に縮退すること。
- LAYER1_FEATURES / FRAME_RESULT_FIELDS / AUTORIETVELD_RESULT_FIELDS ガードを更新すること。

## 非機能要件

- NFR-318-001: 物理コア (`operando.coulometry`) は numpy-only・決定論 (NFR-102 準拠)。
- NFR-318-002: GSAS 依存部は遅延 import + `@pytest.mark.gsas` 隔離。コア import は numpy のみ維持。
- NFR-318-003: 全状態変更は ledger 追記 (P2)。x₀ 校正は提案のみ (提案≠適用)。

## 受入基準 (代表)

- AC-1: 既知 Q/m/M/z に対し n_e が解析値と一致 (26801.5 ピン留め)。
- AC-2: FW₁≠FW₂, Z₁≠Z₂ の 2 相合成データで x_XRD のモル平均が解析値と一致 (FW 除算の検証)。
- AC-3: sign と state の矛盾で警告が出る。in_span=False で制約が適用されない。
- AC-4: lock_fractions の 2 相 GSAS テストで相分率がクーロメトリー解に一致。
  実行不能フレームは縮退+警告。
- AC-5: アンカー A/B で ΔRwp 大のとき警告 + x₀ 校正提案 payload が出る (適用はされない)。
- AC-6: K-10 実データ (247 frames) で ② MCP 経由の E2E が通り、K 量 vs echem 重ね図が得られる。

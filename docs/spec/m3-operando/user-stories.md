## エピック1: マルチスタート大域最適確認

### ストーリー 1.1: 局所解の疑いを晴らす 🔵
**信頼性**: 🔵 *FR-230/§14「GSAS-II最小二乗の発散」緩和*

**私は** 精密化結果を公刊する研究者 **として**
**最終候補の精密化が局所解でないことを、系統摂動した N 本の独立精密化で確認したい**
**そうすることで** 単一 basin なら大域最適の傍証を、複数 basin なら代替解を明示して報告できる

**関連要件**: REQ-001〜006 / **優先度**: Must Have

## エピック2: operando 電池解析

### ストーリー 2.1: 電気化学と回折の同期 🔵
**信頼性**: 🔵 *FR-311/314*

**私は** operando 電池実験の研究者 **として**
**サイクラーの CSV (V/I/Q) をフレームに同期し、wt_frac(x)・格子(x)・転移点 x/V±σ を得たい**
**そうすることで** 電気化学量と構造変化を直接結合した図が作れる

**関連要件**: REQ-007, REQ-011 / **優先度**: Must Have

### ストーリー 2.2: セル由来ピークの自動処理 🔵
**信頼性**: 🔵 *FR-312*

**私は** 研究者 **として**
**Be 窓や Al 集電体のピークをテンプレートで常駐固定相として扱ってほしい**
**そうすることで** セル由来ピークが未知相と誤認されず、活物質の解析に集中できる

**関連要件**: REQ-009 / **優先度**: Must Have

### ストーリー 2.3: 固溶体か二相反応かの自動判別 🔵
**信頼性**: 🔵 *FR-313/P1 (Dara null hypothesis testing の拡張)*

**私は** 研究者 **として**
**充放電区間ごとに「固溶体 (格子連続)」と「二相反応 (分率変化)」の両仮説を定量比較してほしい**
**そうすることで** 反応機構の解釈を evidence に基づいて主張でき、僅差なら要確認と分かる

**関連要件**: REQ-010, REQ-101 / **優先度**: Must Have

### ストーリー 2.4: 充放電ヒステリシスの定量化 🔵
**信頼性**: 🔵 *FR-315*

**私は** 研究者 **として**
**充電枝と放電枝を分離し、同一 x での構造差分を出力してほしい**
**そうすることで** 経路依存性 (ヒステリシス) を定量的に議論できる

**関連要件**: REQ-012, REQ-104 / **優先度**: Should Have

## エピック3: 区間自動分割 (FR-316)

### ストーリー 3.1: 判別区間の人手指定からの解放 🔵

## エピック4: 吸収補正 (FR-317)

### ストーリー 4.1: セル吸収による分率バイアスの補正 🔵
**信頼性**: 🔵 *FR-317/§12-3 ベンチ観点*

**私は** operando 研究者 **として**
**CellConfig から初期化された実効 μt をフィット変数として精密化し、restraint で物理範囲に拘束してほしい**
**そうすることで** セル吸収による相分率バイアスを補正しつつ、暴走も防げる

**関連要件**: REQ-016, REQ-017, REQ-103, EDGE-006 / **優先度**: Must Have

**そうすることで** 情報不足でも解析を止めず、後から CellConfig を補える

**関連要件**: REQ-018 / **優先度**: Must Have

## 自律確定した論点

### Q1: 作業規模
**確定**: フル機能開発。**根拠**: M3 は Dara 非対応領域の中核 (operando) で、§15 の確定事項
(FR-316 探索順序・FR-317 粒度) が仕様に明記済み 🔵。

### Q2: マルチスタート摂動の決定論化
**確定**: 乱数でなく**決定論的固定列** — 格子は ±幅の等間隔グリッド、scale は対数一様グリッド、
占有率は固定ラテン超方格テーブル (start index に対して一意)。
**根拠**: NFR-102「乱数種固定でビット同一」。seed 固定 PRNG も可だが、index ベースの決定論列の
方が再現・デバッグが単純 🟡。FR-231 の摂動種別はそのまま踏襲 🔵。

### Q3: 電気化学入力の実装範囲
**確定**: CSV 汎用マッパのみ実装 (列名マッピング設定式)。Biologic .mpr / 北斗 / HZ は
`EchemLoader` Protocol + 未実装エラー。
**根拠**: .mpr はバイナリ仕様でパーサ依存 (galvani 等) が必要 — コア依存 numpy のみの方針 🔵。
CSV は stdlib で完結 🔵。

### Q4: ExternalChannel の echem 拡張方法
**確定**: 既存 `ExternalChannel` (単値 sync_map) は不変のまま、複数量 (V/I/Q/x) を束ねる
`EchemChannels` (チャネル集合) を新設し、kind に "echem_*" 系を追加 (後方互換の Literal 拡張)。
**根拠**: 既存 API 非破壊 (REQ-404)。単値チャネルの再利用で M2 資産と整合 🟡。

### Q5: セル固定相の「固定」の粒度
**確定**: 固定相 = scale (相分率) のみ解放、格子・その他は固定。探索候補としては常時含まれ、
Jaccard 縮約・枝刈りの対象外 (常駐)。
**根拠**: FR-312 の趣旨 (セル由来ピークの説明)。Be/Al は既知構造で格子精密化は不要 🟡。

### Q6: FR-313 判別の仮説構成
**確定**: (a) 単相仮説 = 区間全フレームを 1 相で warm start 逐次精密化 (格子連続)、
(b) 二相仮説 = 端成分 2 相 (区間端点の格子で固定初期化) の分率変化。両者を区間合計 bic で比較。
**根拠**: FR-313 の定義そのまま 🔵。端成分の初期格子を区間端点から取る具体化は 🟡。

### Q7: FR-316 の evidence 合計とペナルティ
**確定**: 分割 k の合計 evidence = Σ(区間 bic) + ペナルティ (境界 1 個あたり β·ln(総フレーム数)、
β 既定 5.0・設定可)。改善閾値 (既定 10.0) 未満で k 追加を打ち切り。
**根拠**: FR-316「ペナルティ=BIC項」🔵。β の値は実装時較正 (§15-1) のため設定化 🟡。

### Q8: 吸収補正の前方モデル (SimulatedBackend)
**確定**: 透過配置の吸収因子 A(θ; μt) = exp(-μt / cos(θ)) を強度に乗算 (平板透過の簡約)。
μt はパラメータ名 "global.mu_t" として認識し、restraint はペナルティ項 (chi2 加算) で表現。
**根拠**: FR-317 v1「実効 μt 1 パラメータ + restraint」🔵。A(θ) の式形は平板透過の標準近似 🟡。

### Q9: Issue #4 の onset 修正方針
**確定**: disappearing は 90% 交差を onset とし、常に |onset − 遷移開始側| が成立
(onset は direction に依らず「遷移が始まる側」)。フィールド名は維持。
**根拠**: Issue #4 の対応案 1 を採用 (命名変更は API 破壊のため回避) 🔵。

### Q10: Issue #5 の共有先
**確定**: `src/tsumugin/_json.py` に `finite_or_none` (公開名) を新設し、tree.py / webui /
serialization から利用。tree.py のセンチネル対応は tree 側に残す (センチネルは探索固有)。
**根拠**: Issue #5 対応案 + store 最下層からの逆依存回避 (tasknote 指摘) 🔵。

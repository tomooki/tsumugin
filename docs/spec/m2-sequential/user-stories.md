## エピック1: シーケンシャル解析基盤

### ストーリー 1.1: 時系列データの自動逐次解析 🔵
**信頼性**: 🔵 *P5/FR-301*

**私は** in situ 実験の研究者 **として**
**数百フレームの時系列パターンを一括で逐次精密化してほしい**
**そうすることで** フレームごとの手動解析なしに相分率・格子の時間発展を得られる

**関連要件**: REQ-001, REQ-002, REQ-005
**詳細シナリオ**: フレーム列+軸値を渡す → warm start 逐次精密化 → トラジェクトリ (CSV 可) が返る
**優先度**: Must Have

### ストーリー 1.2: 相変化イベントの自動検出 🔵
**信頼性**: 🔵 *FR-303/304*

**私は** 研究者 **として**
**相の出現・消滅が起きたフレームを自動検出し、そこだけ多仮説探索で相構成を見直してほしい**
**そうすることで** 全フレーム木探索の計算コストなしに相変化を見逃さない

**関連要件**: REQ-003, REQ-101, EDGE-104
**優先度**: Must Have

### ストーリー 1.3: 相ライフサイクルの可視化データ 🔵
**信頼性**: 🔵 *FR-305/306*

**私は** 研究者 **として**
**各相の birth/death フレームと確信度を、点滅ノイズなしで追跡してほしい**
**そうすることで** 相図・反応系譜の解釈に直接使える

**関連要件**: REQ-004, REQ-201
**優先度**: Must Have

## エピック2: 高温モード

### ストーリー 2.1: 転移温度の自動推定 🔵
**信頼性**: 🔵 *FR-321/323*

**私は** 高温 in situ 実験の研究者 **として**
**温度チャネルを紐付けて転移温度 (onset/midpoint±σ) を自動推定してほしい**
**そうすることで** 昇温スキャンから転移点を定量的に報告できる

**関連要件**: REQ-006, REQ-008
**優先度**: Must Have

### ストーリー 2.2: 熱膨張と異常の分離 🔵
**信頼性**: 🔵 *FR-322*

**私は** 研究者 **として**
**単調な熱膨張ベースラインと、転移に伴う格子異常を分離してほしい**
**そうすることで** 格子トラジェクトリから物理的イベントだけを抽出できる

**関連要件**: REQ-007
**優先度**: Should Have

## エピック3: 永続化と非破壊性

### ストーリー 3.1: 解析履歴の永続化と再開 🔵
**信頼性**: 🔵 *P2/NFR-101/105*

**私は** 長時間解析の運用者 **として**
**ledger/snapshot をファイルに永続化し、再起動後も改竄検知と revert ができてほしい**
**そうすることで** 大規模シーケンシャル解析の全履歴が監査・復元可能になる

**関連要件**: REQ-010, REQ-011, REQ-012, REQ-401, EDGE-003
**優先度**: Must Have

## エピック4: 最終選択 2 モード

### ストーリー 4.1: エージェント自動裁定 🔵
**信頼性**: 🔵 *FR-402 (agent)*

**私は** 全自動運転を望む運用者 **として**
**明確な最良仮説はエージェントが根拠付きで自動 accept してほしい**
**そうすることで** 人手ゼロで解析が確定し、根拠は ledger でいつでも監査できる

**関連要件**: REQ-013, REQ-014, REQ-102
**優先度**: Must Have

### ストーリー 4.2: 人間最終判断モード 🔵
**信頼性**: 🔵 *FR-402 (human)*

**私は** 結果に責任を持つ研究者 **として**
**エージェントは推奨提示に留め、最終 accept は自分の操作でのみ行いたい**
**そうすることで** 公刊データの最終判断を人間が保持できる

**関連要件**: REQ-103, REQ-104
**優先度**: Must Have

### ストーリー 4.3: 要確認ケースの取りこぼし防止 🔵
**信頼性**: 🔵 *FR-403*

**私は** 運用者 **として**
**僅差競合・未知相などの怪しいケースを Review Queue に集約してほしい (処理は止めずに)**
**そうすることで** 自動運転を維持しつつ、後から要確認ケースだけをまとめて見直せる

**関連要件**: REQ-015, REQ-102, EDGE-004
**優先度**: Must Have

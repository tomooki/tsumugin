## 必須（実装開始前に完了が必要）

なし — M2 は外部サービス・認証情報・追加インフラを必要としない。
テストはすべて合成データで完結し、GSAS-II は導入済み。

    実地検証に使える。M2 のテスト自体には不要

    parquet が必要なら M3 で optional extra として追加する

# fit-then-judge P1.5 — 評価スクリプトの設計

計画は [`docs/tasks/fit-then-judge/p15.md`](../../tasks/fit-then-judge/p15.md)。定義の正は [P0](p0-preregistration.md) で、本書は
それをどう実装に写すかだけを書く。P0 と食い違ったら P0 が正しい (実装を直す)。

## 1. 置き場所と依存

- `tsumugin.prereg_eval` (新パッケージ)。**数値の核は stdlib + numpy だけ** (c(N) の Clopper–Pearson は二項分布の累積を二分法で解く。
  scipy を使わないのは、凍結する評価スクリプトの依存を最小にして環境の指紋を小さくするため)。GSAS を回す「アームの実行」は別モジュールで
  遅延 import に閉じ込める。
- **② (MCP) と ③ (skill) には出さない**。事前登録した実験の道具であって解析の機能ではない (呼ぶのは P2 の 1 回だけ)。
  `tests/test_layer_coverage.py` に理由付きで宣言する。

## 2. 入力の形

アームの実行と指標の計算を分ける。指標の関数はすべて**実行結果を写した不変の値**を受け取り、GSAS を知らない。

| 型 | 中身 |
|---|---|
| `RefValue` | 参照構造の 1 値。`kind` (`coord`/`occupancy`/`cell`)・`key`・値・σ_ref (座標は原子ごとに分率 3 成分と 3 つの σ) |
| `FitValue` | アームの 1 値。`kind`・`key`・値・σ_fit・`refined` (精密化しなかった値は σ_fit = 0 — P0 §1.3) |
| `ArmOutcome` | 1 (事例, アーム)。失敗したか (と理由)・χ²・観測集合のハッシュ・比較集合の値・f (fail 件数)・b (短結合の外れ)・1A の値ごとの状態 |
| `CaseInput` | 1 事例。参照 (無ければ None)・格子行列 (分率 → Å)・アーム名 → `ArmOutcome` |

## 4. 失敗の扱い (P0 §1.2)

- アームの失敗 (例外・error dict・χ² 非有限・未収束・事後の収束検査に外れた) は**比較で失敗した側の負け**。両方失敗は劣化に数えない。
- `unevaluated` は分母から外し、件数を必ず併記する。どの集計も「評価した件数」と「unevaluated の件数」を一緒に返す (片方だけ返す API を作らない)。

## 5. P0 の文言を実装に写すときに決めた解釈

- **構造の部分の 50% 規則の分母** (§1.2): 失敗で決まった事例 ((a) で決着・比較相手の失敗) と両方失敗は分母に入れない。
  失敗した側のアームには比べる構造が無いのであって「評価できなかった」のではないため。入れると、失敗が多いほど構造の
  判定不能が薄まる (失敗が多い手順が得をする)。
- **結論の優先順位** (§2.3): はっきりした不通過 (どちらかの比較で `fail`・反証の発火) があれば、ほかに判定不能があっても `fail`。
  どちらも通過にはならないが、不通過の根拠がある方を報告する。
- **H 単独と合算の合わせ方** (§2.2): どちらかで発火したら発火。どちらも発火せず、どちらかが判定不能なら判定不能
  (片方で発火しなかったことで、もう片方の判定不能を隠さない)。
- **率の分母が 0 の成分は判定不能** (R3 の誤発火率を測る無注入の行が無い、など)。「発火しない」にしない。
- **R1A-2 の「参照のある値が 30 未満」は率ごとに当てる**: `O_det` の分母 (`determined` かつ参照あり) と `O_pub` の分母を別々に数える。
  参照のある値が全体で 300 あっても `determined` が 5 件なら `O_det` は判定不能。ただし `determined` の値が 1 件も無い経路
  (Phase B が無い経路) の `O_det` は空であって判定不能ではない。

## 6. 合成 `S-dev` の生成器 (P0 §6)

- **生成器は `S-eval` でもそのまま使う** (凍結版に入る)。入力は CIF (COD から ID で取得し sha256 を照合)・相と wt%・装置の種類・最大計数・
  乱数の種・注入する欠陥・モデルの不一致。出力はパターン (追跡しない) と事例ごとの manifest (P0 §6.4 の項目すべて。期待する検出器の結果は
  **生成の前に**書く)。
- **構造は型で先に決める** (どの化合物が `H-pub` の候補かを見ずに決める — 候補一覧はまだ作っていない)。必須の型 (§6.1) ごとに 1 つ以上:
  混合占有・極性空間群・結合した特殊位置 ((x,x,x) 等)・多相 (2–3 相、副相 1–10 wt%)。除外: 準 hold-out の化合物・ゲート確認に使った 5 種
  (蛍石・硫酸鉛鉱・石英・方解石・コランダム)・開発用の未公開データの化合物。選んだ化合物は `H-pub` の候補から除く (§3.2.1-2)。
- **装置は生成器の中の合成の値** (実験室 Bragg-Brentano Cu Kα1/Kα2・放射光 Debye-Scherrer)。準 hold-out の装置ファイルを使わない。
- 計算は GSAS-II の calc-only (`add_simulated_powder_histogram` → 1 サイクル) で Ycalc を取り、尺度を合わせて Poisson 雑音を足す。

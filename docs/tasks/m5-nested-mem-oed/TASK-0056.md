## タスク概要
MEM 実行系の密結合な 4 モジュールを 1 タスクに束ねて実装する (いずれも MEMBackend + MEMResult/MEMInput へ
委譲・相互に参照し合う)。
- `mem/guard.py` (**警告のみ・除外しない, D7**): `MEMApplicabilityReport` (recommended / is_single_phase /
  is_dominant_phase / warnings)。`check_mem_applicability(verification: JointVerificationResult, hypothesis_id)`
  — joint 済み単相/主相支配的なら recommended=True。多相/低統計でも `recommended=False` + warnings を返すのみで
  MEM 実行を中止せず、**仮説除外・rejected 化を一切行わない** (Dara 教訓, REQ-030/031/103/EDGE-007)。
- `mem/output.py`: `write_density_map(mem_result, path) -> str` (VESTA 互換 .grd, REQ-027) /
  `extract_cross_section(density_map, *, start, end, dimension=1, label="") -> DensityCrossSection`
  (1D/2D 断面, REQ-028) / `bond_path_min_density(density_map, *, start_site, end_site, start, end) ->
  BondPathDensity` (伝導ボトルネック最小密度, REQ-029)。
- `mem/iterate.py` (**既定オフ・子スナップショット追記・親不変, D6**): `MEMRietveldConfig` (enabled=False /
  max_iter=5 / r_tol / density_tol) / `MEMRietveldCycle` (iteration / snapshot_id / r_factor / mem_result) /
  `MEMRietveldResult` (cycles / stop_reason: converged|max_iter|diverged|disabled / warnings)。
  `run_mem_rietveld(backend, mem_backend, joint_result, parent_phases, probe, *, config, snapshots, ledger=None)`
  — enabled=False なら stop_reason="disabled" を即返す。有効時は MEM 密度→F_calc 更新→再精密化の MPF サイクルを
  回し、各サイクルの phases を `snapshots.save(..., label="mem_rietveld_iter{n}")` で**子スナップショット追記**
  (親不変・削除/上書きしない, REQ-025/202/NFR-005/P2)。収束 (R/密度変化<tol) or max_iter で停止し理由を ledger
  記録 (REQ-026/EDGE-009)。発散 (密度負値/R 悪化) は当該サイクルを子スナップショットに残しつつ停止・
  stop_reason="diverged"・ledger 記録 (ロールバックは revert 経由・破壊しない, REQ-107/EDGE-008)。
- `mem/spot.py`: `run_mem_spot(backend, mem_backend, series: FrameSeries, verification, hypothesis_id,
  frame_index, probe, *, grid_shape=(64,64,64), ledger=None) -> MEMResult` — 指定単一フレーム (充電端/放電端/
  転移前後) の joint 検証済み仮説に MEM をスポット実行。全フレーム自動反復しない (spot 単位完結, REQ-032/405)。
  check_mem_applicability の警告を MEMResult.warnings に伝播 (除外しない, REQ-031)。

`mem/__init__.py` で re-export。全て SDK/バイナリ非依存 (MEMBackend はモックで通常 pytest 網羅)。

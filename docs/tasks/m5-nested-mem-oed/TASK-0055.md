## タスク概要
`mem/dysnomia.py` に Dysnomia 外部バイナリの MEMBackend ラッパを新設する (遅延起動)。
- `DysnomiaBackend` frozen dataclass (binary_path=None (None は PATH 探索) / work_dir=None (None は tempdir) /
  name="dysnomia")。`MEMBackend` Protocol を実装。
- `run(mem_input: MEMInput) -> MEMResult`:
  一時領域に MEM 入力ファイルを**決定論的に生成** → Dysnomia バイナリを**遅延起動** → 密度マップ (.grd) 等を
  回収する。**入出力ファイル契約を固定** (REQ-406/NFR-106)。生データ改変はしない (P2)。
  **バイナリ未検出時は `MEMUnavailableError` (M4 で errors.py 定義済) へ縮退**する (REQ-020/EDGE-006)。
  `import tsumugin.mem.dysnomia` はコア (numpy) のみで成功する。

`@pytest.mark.mem` で実バイナリ依存テスト (TC-515-04 smoke) を分離し未導入環境で自動 skip。未導入時
`MEMUnavailableError` (TC-506-02) はモック/非依存で通常 pytest 網羅。**pytest marker `mem` の未登録 warning
回避のため conftest.py marker 登録を本タスクで前倒し可** (extra 本体列挙は 0058。pyproject/conftest の同一
箇所は 0050→0055→0058 の直列で 1 タスクずつ触る)。Dysnomia/dynesty/ultranest/pyboed の contract test は
バージョン固定 (REQ-406/NFR-106) — 実バイナリ導入時に入出力契約を凍結。`mem/__init__.py` で re-export。

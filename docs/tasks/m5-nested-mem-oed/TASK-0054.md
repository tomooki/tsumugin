## タスク概要
`mem/inputgen.py` に精密化済み joint 結果からの F_obs 抽出・MEM 入力生成を新設する (D5)。
- `StructureFactor` frozen dataclass (hkl: (int,int,int) / f_obs / phase (モデル由来ラジアン) / d_spacing)。
  決定論のため反射は (h,k,l) 昇順で保持 (REQ-023/NFR-102)。
- `MEMInput` frozen dataclass (structure_factors ((h,k,l) 昇順) / density_kind: electron|nuclear / lattice
  (a,b,c,α,β,γ) / space_group / grid_shape / lambda_start=1.0)。
- `extract_structure_factors(joint_result: JointRefinementResult, *, hist_index=0) -> tuple[StructureFactor, ...]`:
  joint 集約 (RefinementResult) の精密化済み構造から F_calc の位相を借り、観測強度由来の |F_obs| と組んで
  StructureFactor を構成する (位相はモデル由来, REQ-021)。反射は (h,k,l) 昇順で返し、同一仮説から 2 回抽出で
  ビット同一 (NFR-102/REQ-402)。
- `build_mem_input(joint_result, probe: Probe, *, hist_index=0, grid_shape=(64,64,64)) -> MEMInput`:
  probe で密度種別を分岐 (**xray→electron / neutron_cw・neutron_tof→nuclear**, REQ-022)。
  extract_structure_factors の (h,k,l) 昇順を継ぎ、同一入力でビット同一 MEMInput を生成 (REQ-023)。

入力元は `joint/verification.py::verify_survivors` の `JointRefinementResult` (D5)。`Probe` は既存
`model.project.Probe`。本タスクは MEMBackend 実装に**非依存** (入力生成のみ・0053 の MEMInput 型を使う)。
`mem/__init__.py` で re-export。

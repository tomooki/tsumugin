## タスク概要
`nested/laplace.py` に `LaplaceBackend` frozen dataclass (name="laplace") を新設。既存 `EvidenceBackend`
Protocol (`name` + `score(metrics) -> EvidenceResult`) に準拠し、既存 `rank`/`evidence` 経路に混在可能とする
(符号規約: value 小さいほど良い, REQ-003)。
- `score(metrics)`: metrics のみの狭い経路。Hessian を持たないため **BIC 近似 (chi2 + k ln n) へ縮退**し
  `EvidenceResult(backend="laplace", value=-logZ 相当)` を返す (REQ-002/003)。
- `score_problem(problem: EvidenceProblem)`: 尤度 + MAP + Hessian を用いた Laplace 近似 evidence
  `value = -( logL_map + (k/2)ln(2π) - (1/2)ln|H| )` を符号統一 (-logZ) で返す。**Hessian が特異/取得不能
  なら `score(metrics)` の BIC 近似へフォールバックし警告を `EvidenceResult` に残す** (例外化しない,
  REQ-002/EDGE-005)。

`EvidenceProblem` 型は TASK-0049 で定義 (前提)。本タスクでは `score_problem` の引数型注釈を文字列前方参照
(`"EvidenceProblem"`) または TASK-0049 マージ後の実体で受ける。`nested/__init__.py` で `LaplaceBackend` を
re-export (パッケージ内に閉じる。トップレベル `__all__` 追加は TASK-0058)。
本 backend は nested 打ち切り時の代替先 (REQ-101/D3) として NestedBackend が保持する。

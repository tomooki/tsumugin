## タスク概要
`mem/base.py` に MEM ソルバの交換可能境界 (`RefinementBackend`/`EvidenceBackend`/`ChemPlausibility` と同型
Protocol) と結果 dataclass 群を新設する。
- `MEMDensityMap` frozen dataclass (path / density_kind: electron|nuclear / grid_shape (nx,ny,nz) /
  min_density / max_density)。実密度グリッドはファイル参照、メモリには要約統計のみ (重データを引き回さない)。
- `DensityCrossSection` frozen dataclass (label / dimension: 1|2 / coordinates: np.ndarray / values: np.ndarray)。
- `BondPathDensity` frozen dataclass (start_site / end_site / min_density / path_length)。伝導ボトルネック抽出用。
- `MEMResult` frozen dataclass (density_map / cross_sections=() / bond_paths=() / r_factor=None / converged=True
  / warnings=())。**非破壊**: 密度は path 参照で親仮説/joint 結果を書き換えない。適用ガード警告は warnings に
  積むが仮説除外はしない (Dara 教訓, REQ-031)。
- `MEMBackend` runtime_checkable Protocol (`name` + `run(mem_input: "MEMInput") -> MEMResult`)。v1 実装は
  DysnomiaBackend (TASK-0055)。将来の内製/他ソルバも本 IF で交換可能。

`MEMInput` 型は TASK-0054 で定義。本タスクでは `run` の引数型注釈を文字列前方参照 (`"MEMInput"`) で受ける。
未導入バックエンドが `MEMUnavailableError` (M4 定義済) を送出する契約を Protocol docstring で明示する
(実処理は 0055)。`mem/__init__.py` で re-export (トップレベル `__all__` は TASK-0058)。

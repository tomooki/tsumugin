## タスク概要
`errors.py` 末尾に `NestedUnavailableError(TsumuginError)` と `OEDUnavailableError(TsumuginError)` を
**非破壊追記** する。M4 で定義済の `MEMUnavailableError` / `MCPUnavailableError` / `WebUIUnavailableError` /
`GSASUnavailableError` と同型の「available + 専用例外」パターン。
- `NestedUnavailableError`: optional extra `nested` (dynesty/ultranest) 未導入で `NestedBackend.score_problem`
  (実サンプラ起動経路) を要求したときに送出 (REQ-005/EDGE-001)。`import tsumugin` / `import tsumugin.nested`
  自体は成功する。
- `OEDUnavailableError`: optional extra `oed` (pyboed) 未導入で `acquire` (獲得関数接続 API) を要求したとき
  に送出 (REQ-036/EDGE-011)。v1 提案生成 `propose_measurements` は本例外に非依存で動作する。

両例外は `errors.py` の末尾追加のみ。トップレベル `tsumugin/__init__.py` の `__all__` への追加は
**TASK-0058 に集約** (直列化ホットスポット回避) するため、本タスクでは行わない。

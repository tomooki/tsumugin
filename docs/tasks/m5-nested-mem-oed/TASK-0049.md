## タスク概要
既存 `EvidenceBackend` Protocol は**不変**に保ち (D1)、nested/laplace が必要とする追加入力を補助 dataclass に
束ねて別メソッドで受け渡す拡張境界を新設する。
- `nested/base.py`:
  - `PriorSpec` frozen dataclass (param_name / kind=uniform|normal|truncated_normal / low / high / loc / scale
    + `transform(u)` 逆 CDF 変換)。単位区間 [0,1] を物理量へ写す。
  - `EvidenceProblem` frozen dataclass (metrics + `log_likelihood: Callable[[np.ndarray], float]` + `priors`
    (param_name 昇順) + `map_point` + `hessian` + label)。EvidenceBackend.score(metrics) の狭いシグネチャで
    渡せない尤度/事前分布/MAP/Hessian を束ねる。縮退時に BIC/Laplace へ渡す metrics も同梱。
  - `ProblemAwareEvidenceBackend` runtime_checkable Protocol (`name` + `score(metrics)` + `score_problem(problem)`)。
    既存 `EvidenceBackend` を構造的に包含し、bic/aic は非実装のまま (後方互換)、laplace/nested のみ実装する。
- `nested/prior.py`:
  - `RestraintSpec` frozen dataclass (param_name / lower / upper / center / sigma)。既存 free_params 命名
    (`phase{i}.{key}` / `global.{key}`) と整合。
  - `build_prior_from_restraints(free_params, restraints=(), *, overrides=None) -> tuple[PriorSpec, ...]`:
    各 free_param に restraint から区間/中心を割り当て uniform/truncated_normal を構成 (格子=±数%, 占有率=[0,1]
    等の種別既定)。`overrides` (param_name→PriorSpec) で手動上書き (REQ-301)。返す tuple は param_name 昇順で
    決定論化 (nested 次元順固定, NFR-102/REQ-402)。

既存 `backends.base` の param_name/parse_param (`global.{key}` 対応) 命名と整合させる。`nested/__init__.py` で
re-export (トップレベル `__all__` は TASK-0058)。

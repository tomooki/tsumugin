## タスク概要
`nested/sampler.py` に nested sampling evidence バックエンドを新設する。
- `NestedConfig` frozen dataclass (sampler=dynesty|ultranest / seed=0 / n_live=400 / time_limit_sec=1800.0 /
  max_calls=None)。種固定で再現性 (NFR-102 の nested 例外)、実装選択 (REQ-303)、時間上限 (REQ-101/NFR-103)。
- `NestedOutcome` frozen dataclass (result: EvidenceResult / logz / truncated=False / warnings=())。
  打ち切り時は result=Laplace 代替値・logz=None・truncated=True。
- `NestedBackend` frozen dataclass (config / laplace=LaplaceBackend / name="nested"):
  - `score(metrics)`: 尤度関数を欠くため **Laplace 代替へ委譲** (縮退, REQ-007/101)。
  - `score_problem(problem)`: **dynesty/ultranest を遅延 import** (実行時のみ)。未導入なら
    `NestedUnavailableError` を送出し extra 導入手順を案内する。`import tsumugin.nested.sampler` はコア
    (numpy) のみで成功 (TC-502-02)。value=-logZ + logz_err を返す。seed 固定で 2 回実行し logZ が logz_err
    範囲内で一致 (ビット同一でなく誤差範囲一致, REQ-009/EDGE-014)。
  - `run_with_fallback(problem, *, ledger=None) -> NestedOutcome`: time_limit_sec 超過や
    `NestedUnavailableError` を**例外化せず** truncated=True + Laplace 代替 value + 警告として返す (解析を
    止めない, REQ-101/405/EDGE-002)。ledger 非 None のとき打ち切りを記録 (REQ-013)。

`@pytest.mark.nested` で実サンプラ依存テスト (TC-502-03/04) を分離し未導入環境で自動 skip。境界・縮退・
Laplace 代替 (TC-502-01/02, TC-504-01/02) はモック/非依存で通常 pytest 網羅。**pytest marker `nested` の
未登録 warning を避けるため conftest.py への marker 登録を本タスクで前倒し可** (extra 本体列挙は 0058。
pyproject/conftest の同一箇所は 0050→0055→0058 の直列で 1 タスクずつ触る)。`nested/__init__.py` で re-export。

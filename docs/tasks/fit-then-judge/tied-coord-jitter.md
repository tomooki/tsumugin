# 結束した座標への摂動 (収束確認 Phase B) — 確認結果と修正

P1-1B の「既知の限界」に残した問い: 収束確認の座標摂動 (`engine._apply_coord_jitter`) は結束した座標
((x,x,x)・(x,2x,z)・(x,-x,0) 等) の**代表軸だけ**を書き換えていた。GSAS-II が精密化の前か途中で従属座標を
代表へ揃え直すなら問題は無いが、揃え直さなければ開始点は対称性を破った位置から出発し、偽の割れ
(`claims` の `initial_value_dependent`) を作り得る。

## 結果 (2026-10-13, 実 GSAS-II)

**揃え直さない。** GSAS は結束を**シフト**の等値 `dAy = (cy/cx)·dAx` (`GSASIIstrIO.py:1760-1765`) として
張るだけで、座標そのものは書き換えない。代表と従属のずれは精密化の最後まで残る。

合成 pyrite FeS2 (Pa-3, S は 3 回軸上 (x,x,x)・site `3(111)`; 真値 x=0.3848、出発 x=0.3800、Cu Kα1 の
計算パターン + Poisson ノイズ)、`initial_coord_jitter={"FeS2": 0.05}` (Å):

| 開始点 | 精密化後の S (x, y, z) | 摂動なしとの一致 (`parameter_agreements`) |
|---|---|---|
| 摂動なし | (0.38481, 0.38481, 0.38481) | — |
| 種 2 (修正前) | (0.38187, 0.38627, 0.38627) | 一致 (esd/床の内側) |
| 種 3 (修正前) | (0.37972, 0.38737, 0.38737) | **DISAGREE** (x・y・z の全部) |

Rwp はどの開始点も 5.765% で同じ — 「同じくらい合っている」のに座標は違う、の典型。修正前の Phase B は
結束原子を持つ構造で偽の割れを報告し得た。

## 修正

代表の乱数 1 回ぶんの変位を、`GetCSxinel` の係数比 `xCoef[軸]/xCoef[代表]` (GSAS が張る等値と同じ) で
従属軸にも掛ける (`atomrows.tied_axis_groups`)。

- 乱数は独立変数ごとに 1 回のまま — 結束原子を持たない構造の摂動は以前とビット同一。
- 摂動なしの既定経路は通らない (ビット同一)。
- `coord_jitter_axes_moved` は独立変数の数のまま (結束の組は 1 と数える)。
- 振幅の契約 (**どの軸の変位も amp Å 以下**) を結束原子にも保つ: 分率へ直すとき、組の中で
  |倍率|·軸長 が最大の軸で割る ((x,2x,z) の y は x の 2 倍動くため)。組が 1 軸なら従来と同じ割り算。
- 未知の sytsym の原子は従来どおり振らない — engine (`_phase_atom_info`) がその原子の座標を解放しないので、
  振ると摂動値がそのまま最終解になる (凍結原子と同じ偽の割れ)。

テスト: `tests/autorietveld/test_coord_jitter_tied_gsas.py` (gated; 精密化後に結束が保たれ、種 2・3 が
摂動なしの x から 1e-5 以内 (修正後の実測は 5e-7 以内) に戻り、`parameter_agreements` でも一致) と
`tests/autorietveld/test_coord_jitter.py` (係数 −1・1・1/2・2、従属軸も amp Å 以下、乱数を余計に引かない)。
絶対値の判定を置くのは、種 2 の修正前のずれ (2.9e-3) が esd/床の内側で一致判定だけでは捕まらないため。
変異証明: 代表だけ動かす (gated + 単体 3 件が落ちる)・係数を掛け算にする・従属軸ごとに乱数を引く・
結束の検査を外して一致判定だけ残す (種 3 の DISAGREE で落ちる)・結束と一致の検査を両方外して絶対値の判定だけ残す
(種 2 で落ちる)・代表の軸長だけで割る (倍率 2 のテストが落ちる) の 6 つはいずれも落ちる。

## 影響

- この修正より前の Phase B (収束確認) で、結束した座標を持つ構造に出た座標の `DISAGREE` /
  `initial_value_dependent` は偽の割れの可能性がある — 回し直す。
- P1-1B (`milestone/fit-then-judge-1b`) の記述は修正前の挙動を前提にしている。マージ時に合わせる:
  - `p1-1b.md` 既知の限界の「結束した座標 …… 確かめていない」の項は、上の結果 (GSAS は揃え直さない →
    Phase B は従属軸も係数どおり動かす) に置き換える。
  - プローブ (`fixed_magnitude=True`) が結束軸を飛ばす理由は無くなった。`coord_jitter_moved` が代表軸だけを
    記録する点・プローブで結束軸を振るかは P1-1B 側で決める (振るなら証人を従属軸にも付けられる)。
  - 1b の `_apply_coord_jitter` は同じループを書き換えているので衝突する。乱数の引き方 (代表で 1 回) を
    保ったまま `tied_axis_groups` の組で書き込む形に合わせる。

## 不変条件 (全タスク共通)

- 既定経路はビット同一 (P1a のゴールデン `tests/autorietveld/golden/`)。`"template"` は `DEFAULT_CANDIDATES` に入れない。
- 新しいフラグ・フィールドを使うテストは (準) hold-out (T1・CaTeO3・T3 の X 線・T4 の 11-BM) を参照しない
  (`tests/test_holdout_guard.py` に部品名を登録)。**RRUFF の測定パターンも開発に使わない** (P0)。
- 実データの検査は合成 (`S-dev`: hold-out と別の構造から GSAS で作ったパターン) で行う。開発用の未公開データを使ったら結果は
  リポジトリの外に記録する。新しい公開チュートリアルの化合物を使ったら下の「開発に使ったデータ」に記録する (P0 の除外のため)。

## 実データで見つけたこと (タスク 11)

合成データのテストはすべて green だったが、実 GSAS (T2 garnet) を ② 経由で回して 2 件見つかった:
相集合の完全性の証人が強い反射の裾を欠落相と取り違えていた (→ 平均 0 の山形の窓) / 結合原子価和が
混合占有サイトで例外になり常に unevaluated だった (→ 占有率で重み付けた自前の和)。gated の e2e テスト
(`tests/mcp/test_claims_gsas.py`) に固定した。

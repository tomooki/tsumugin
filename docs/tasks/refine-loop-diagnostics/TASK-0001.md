## 実装詳細

### 1. 内省フィールドの末尾追加 🔵
**信頼性**: 🔵 *interfaces.py REQ-001 節 / architecture.md「内省フィールド設計」表*

`AutoRietveldResult` (frozen dataclass) に以下 8 フィールドを**すべて既定空で末尾追加**する。
Mapping は `field(default_factory=dict)`、tuple は `= ()`。既存フィールドより後ろに置き、
位置引数呼び出しの互換を保つこと。 **実装ファイル**: `src/tsumugin/autorietveld/model.py`

```python
# --- 内省フィールド (REQ-001, 非破壊・末尾追加・既定空) ---
atom_uiso: Mapping[str, Mapping[str, float]] = field(default_factory=dict)
# phase_name → atom_label → Uiso。Uiso 発散/負値の検出源 (REQ-105)
atom_occupancy: Mapping[str, Mapping[str, float]] = field(default_factory=dict)
# phase_name → atom_label → 占有率。[0,1] 逸脱の検出源 (REQ-106 隣接)
hist_absorption: tuple[float, ...] = ()
# per-hist の現吸収値。SetAbsorption 判断源 (REQ-106)
hist_profile: tuple[Mapping[str, float], ...] = ()
# per-hist の現プロファイル値 (Zero/alpha/X/Y/U/V/W 等)
peak_width_ratio: tuple[float, ...] = ()
# per-hist の obs/calc FWHM 比 (1.0 が理想)。幅ずれ検出 (REQ-103)
asymmetry_metric: tuple[float, ...] = ()
# per-hist の残差左右非対称度 (0=対称)。非対称検出 (REQ-101)
intensity_bias_metric: tuple[float, ...] = ()
# per-hist の系統 obs>calc 度 (選択配向徴候, REQ-102)
bg_extrema: tuple[int, ...] = ()
# per-hist の背景極値数 (過多=overfit, REQ-104)
```

- `typing.Mapping`・`dataclasses.field` の import が未追加なら足す。
- 既存フィールドの型注釈・順序は変更しない (DD-3 非破壊拡張)。
- `AutoRietveldResult` に `with_updates()` があればそれ経由でも更新可能なこと (frozen 非破壊更新)。

## 注意事項
- numpy コア + GSAS 遅延 import: 本フィールドの算出は runner (GSAS 側) が担い、コアは値を消費するのみ。
  model.py に GSAS import を持ち込まない。
- frozen dataclass 非破壊: 上書き API を足さない。更新は `dataclasses.replace`/`with_updates` のみ (P2)。
- 決定論 (NFR-102): 既定値は不変オブジェクト (空 dict/空 tuple)。可変既定値の共有を避けるため Mapping は
  必ず `field(default_factory=dict)` を使う。
- すべて末尾追加で既存の位置引数/呼び出しを壊さないこと (EDGE-001 後方互換)。

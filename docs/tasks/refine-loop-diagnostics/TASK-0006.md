## タスク概要

「解放」でなく「**限定**」を表す新 SafeAction `RestrictUiso` を `src/tsumugin/refine_loop/action.py` に
追加する (REQ-004)。Uiso 解放対象を重原子/可動イオン/水などのラベルに限定し (Uiso 発散/負値の防止)、
`PhaseSpec.free_uiso_labels` を設定した `AnalysisInput` を返す純変換 (`dataclasses.replace`)。あわせて
`src/tsumugin/refine_loop/diagnostics.py` の `propose_next_actions` に、`diverged_uiso_labels` を検出
したら `RestrictUiso` を提案する規則を足す (REQ-105)。SafeAction なので revert ガード下で自律適用可。

## 実装詳細（項目ごと 🔵 + 実装ファイルパス + Python コード例）

### 1. RestrictUiso SafeAction の追加 (REQ-004) 🔵
**信頼性**: 🔵 *interfaces.py `RestrictUiso` 節 / architecture.md DD-1「限定/値固定」*

`action.py` の SafeAction 群 (`AdjustBackground`/`ReleaseParams`/`Stop`) に並べて追加する。
`PhaseSpec.free_uiso_labels` (既存フィールド) を `labels` に設定する純変換。
**実装ファイル**: `src/tsumugin/refine_loop/action.py`

```python
@dataclass(frozen=True)
class RestrictUiso(SafeAction):
    """Uiso 解放対象を限定する(発散防止)。free_uiso_labels を設定する純変換。

    :param labels: Uiso を解放する原子ラベル(重原子/可動イオン/水など)
    :param phase: 対象相名(None なら全相)
    """

    labels: tuple[str, ...]
    phase: str | None = None

    def apply(self, inp: AnalysisInput) -> AnalysisInput:
        phases = tuple(
            dataclasses.replace(p, free_uiso_labels=self.labels)
            if (self.phase is None or p.phase_name == self.phase)
            else p
            for p in inp.phases
        )
        return dataclasses.replace(inp, phases=phases)
```

- `phase` 指定時に該当相が存在しない場合は既存 ModelAction (`RemovePhase` 等) と同様に
  黙って全相を変更しない (該当なしなら実質恒等)。テストは phase 指定で該当相のみ変わることを確認する。
- `PhaseSpec.free_uiso_labels` は既存フィールド (`autorietveld/model.py`)。空なら uiso 段で全原子解放、
  非空なら限定解放という既存セマンティクスをそのまま利用する。

### 2. propose_next_actions に Uiso 発散 → RestrictUiso 規則を追加 (REQ-105) 🔵
**信頼性**: 🔵 *interfaces.py REQ-105 節 / dataflow.md S5 (C5)*

`diagnostics.py` の import に `RestrictUiso` を足し、`for f in features:` ループ内で
`diverged_uiso_labels` が非空なら提案する。
**実装ファイル**: `src/tsumugin/refine_loop/diagnostics.py`

```python
# Uiso の発散/負値 → 解放対象を限定 (RestrictUiso, REQ-105)
if f.diverged_uiso_labels:
    proposals.append(
        ActionProposal(
            action=RestrictUiso(tuple(f.diverged_uiso_labels)),
            rationale=f"hist{f.hist_id}: Uiso 発散/負値 {f.diverged_uiso_labels} "
            f"→ Uiso 解放を重原子/可動イオン/水に限定 (発散防止)",
            priority=float(len(f.diverged_uiso_labels)),
            evidence={"signal": "uiso_diverged",
                      "diverged_uiso_labels": tuple(f.diverged_uiso_labels),
                      "hist_id": f.hist_id},
            safe=True,
        )
    )
```

- `diverged_uiso_labels` に**どの原子を残すか**の材料固有判断は焼き込まない (REQ-405)。診断は
  「発散した原子集合」を渡し、`RestrictUiso` は解放対象をそれに限定する候補を出すだけ。採否は
  try→revert が決める。
- 末尾ソートキー (`(not p.safe, -p.priority, type(p.action).__name__)`) は不変 (REQ-402)。

## 注意事項（numpy コア/GSAS 遅延/frozen 非破壊/決定論 NFR-102/材料固有結論を焼き込まない REQ-405）
- numpy コア + GSAS 遅延: `action.py`/`diagnostics.py` は純データ層 (numpy のみ)。GSAS import を
  持ち込まない。`diverged_uiso_labels` の算出は runner (GSAS 側) / diagnose_residual が担う。
- frozen 非破壊 (P2): `RestrictUiso` は frozen。`apply` は `dataclasses.replace` の純変換で入力を破壊
  しない。上書き API を足さない。
- 決定論 (NFR-102/REQ-402): 末尾ソートキーは不変。乱数なし。同一入力でビット同一。
- 材料固有結論を焼き込まない (REQ-405): どの原子を限定対象にするかは診断が渡す `diverged_uiso_labels`
  に委ね、規則は限定候補を列挙するだけ。採否は try→revert が決める。

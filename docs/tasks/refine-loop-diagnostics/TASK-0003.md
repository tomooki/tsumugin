## タスク概要

`src/tsumugin/refine_loop/diagnostics.py` の `ResidualFeatures` (frozen dataclass) に新シグナル
フィールドを**すべて既定 0/空で末尾追加**し (EDGE-001 縮退)、`propose_next_actions` に**非対称/位置
ズレ**の診断規則を追加する。核心は DD-2「別々の候補」: 非対称残差を検出したら、シフト補正 (Zero) と
非対称補正 (X線 SH/L・TOF alpha/beta) を **1 提案に束ねず 2 つの独立した `ReleaseParams` 提案**として
列挙する。どちらが効くかは結論を焼き込まず (REQ-405)、policy が個別に試し `_accept` (Rwp 改善 ∧
validity 維持) が採否を決める。放射源 (`radiation_is_tof`) で非対称候補が SH/L か alpha/beta かを
分岐する。提案順序は既存どおり決定論 (safe 優先 → 優先度降順 → 型名昇順, REQ-402)。

### 1. ResidualFeatures へ新シグナルを末尾追加 🔵
**信頼性**: 🔵 *interfaces.py `ResidualFeaturesExt` / architecture.md「内省フィールド設計」*

既存フィールド (`hist_id` / `low_freq_bg_residual` / `fwhm_ratio` / `unindexed_peak_frac` /
`edge_low_snr` / `n_background_coeffs`) の後ろに、既定 0/空で足す (DD-3 非破壊拡張)。
**実装ファイル**: `src/tsumugin/refine_loop/diagnostics.py`

```python
@dataclass(frozen=True)
class ResidualFeatures:
    hist_id: int
    low_freq_bg_residual: float = 0.0
    fwhm_ratio: float = 1.0
    unindexed_peak_frac: float = 0.0
    edge_low_snr: bool = False
    n_background_coeffs: int = 6
    # --- 追加シグナル (REQ-002/101〜106, すべて既定 0/空 = シグナルなし縮退) ---
    asymmetry_residual: float = 0.0          # 非対称度 (>tol で Zero/非対称候補) REQ-101
    intensity_bias: float = 0.0              # 系統 obs>calc (>tol で PO 候補) REQ-102 (TASK-0004)
    bg_extrema_count: int = 0                # 背景極値数 (過多で減項候補) REQ-104 (TASK-0005)
    diverged_uiso_labels: tuple[str, ...] = ()   # 発散/負 Uiso 原子 → RestrictUiso REQ-105 (TASK-0006)
    absorption_uncertain: bool = False       # 吸収不確実 → SetAbsorption 三択 REQ-106 (TASK-0007)
    radiation_is_tof: bool = False           # TOF か (非対称候補 alpha/beta vs SH/L 分岐)
```

- 本タスクで消費するのは `asymmetry_residual` と `radiation_is_tof`。残り 4 つは後続タスク
  (0004〜0007) が使うが、フィールド追加は競合を避けるため本タスクで一括して行う。

### 2. propose_next_actions に非対称/位置ズレ規則を追加 🔵
**信頼性**: 🔵 *interfaces.py REQ-101 節 / dataflow.md「非対称/位置の切り分けシーケンス」/ DD-2*

`propose_next_actions` の `for f in features:` ループ内に規則を足す。`asymmetry_tol` 引数
(既定 0.1 程度) を追加し、`f.asymmetry_residual > asymmetry_tol` のとき **2 つの別々の提案**を出す。
**実装ファイル**: `src/tsumugin/refine_loop/diagnostics.py`

```python
# 非対称/位置ズレ残差 → シフト(Zero) と 非対称 を「別々の候補」で列挙 (DD-2, REQ-101/405)
if f.asymmetry_residual > asymmetry_tol:
    prio = float(f.asymmetry_residual)
    # (a) シフト候補: Zero を Lorentzian 段で解放 (位置ズレ吸収)
    proposals.append(
        ActionProposal(
            action=ReleaseParams("zero", {"profile_lorentzian": True}),
            rationale=f"hist{f.hist_id}: 非対称/位置ズレ残差 {f.asymmetry_residual:.2f} "
            f"→ ゼロシフト(Zero)解放を試行 (別候補; 採否は try→revert)",
            priority=prio,
            evidence={"signal": "asymmetry", "kind": "zero_shift",
                      "asymmetry_residual": f.asymmetry_residual, "hist_id": f.hist_id},
            safe=True,
        )
    )
    # (b) 非対称候補: 放射源で SH/L(X線) か alpha/beta(TOF) を分岐 (DD-4 prior は列挙自体は常に)
    if f.radiation_is_tof:
        asym_action = ReleaseParams(
            "asym_tof", {"tof_profile": ["alpha", "beta-1", "sig-1", "sig-2"]}
        )
        asym_note = "TOF 非対称(alpha/beta)解放"
    else:
        asym_action = ReleaseParams("asym", {"profile_asymmetry": True})
        asym_note = "X線 非対称(SH/L)解放"
    proposals.append(
        ActionProposal(
            action=asym_action,
            rationale=f"hist{f.hist_id}: 非対称残差 {f.asymmetry_residual:.2f} → {asym_note} "
            f"を試行 (別候補; どちらが効くかは焼き込まない REQ-405)",
            priority=prio,
            evidence={"signal": "asymmetry", "kind": "peak_asymmetry",
                      "radiation_is_tof": f.radiation_is_tof, "hist_id": f.hist_id},
            safe=True,
        )
    )
```

- `propose_next_actions` の末尾ソート (`proposals.sort(key=lambda p: (not p.safe, -p.priority,
  type(p.action).__name__))`) は不変 (REQ-402 決定論)。Zero 候補と非対称候補は同 priority のため
  型名昇順で安定に並ぶ (両者 `ReleaseParams` なので label 差は順序不変・列挙順を保つ安定ソート)。
- 結論を焼き込まず両方を候補として列挙する (REQ-405 / DD-2)。

## 単体テスト要件（Given/When/Then + テストファイルパス）
**テストファイル**: `tests/refine_loop/test_diagnostics_asymmetry.py`

### TC-101-01: 非対称で 2 提案 🔵
**Given** `asymmetry_residual > tol` の `ResidualFeatures` (X線, `radiation_is_tof=False`)。
**When** `propose_next_actions(result, features)` を呼ぶ。
**Then** 「Zero 候補」(`ReleaseParams("zero", {"profile_lorentzian": True})`) と「非対称候補」
(`ReleaseParams("asym", {"profile_asymmetry": True})`) の **2 提案**が別々に含まれる。

### TC-101-02: 両提案とも is_safe 🔵
**Given** 上と同じ非対称シグナル。
**When** 提案を得る。
**Then** Zero 候補・非対称候補ともに `proposal.safe is True` かつ `proposal.action.is_safe is True`
(両者 `ReleaseParams` = `SafeAction`)。

### TC-101-04: 放射源で SH/L vs alpha/beta 分岐 🔵
**Given** (a) `radiation_is_tof=False` の非対称 feature / (b) `radiation_is_tof=True` の非対称 feature。
**When** それぞれ提案を得る。
**Then** (a) では非対称候補が `profile_asymmetry`(SH/L)、(b) では `tof_profile` に
`["alpha", "beta-1", "sig-1", "sig-2"]` (alpha/beta) を含む。

### TC-101-03: 決定論順序 🔵
**Given** 同一の非対称 feature 列。
**When** `propose_next_actions` を 2 回呼ぶ。
**Then** 提案順序がビット同一 (safe 優先 → 優先度降順 → 型名昇順, REQ-402)。

### TC-101-E01: 非対称なしでは出さない 🔵
**Given** `asymmetry_residual <= tol` (既定 0.0 含む) の feature。
**When** 提案を得る。
**Then** Zero 候補・非対称候補のいずれも列挙されない (FP 回避, EDGE-102)。既存の背景/FWHM/未指数
提案は非回帰。

## 注意事項（numpy コア/GSAS 遅延/frozen 非破壊/決定論 NFR-102/材料固有結論を焼き込まない REQ-405）
- numpy コア + GSAS 遅延: `diagnostics.py` は numpy のみ。`asymmetry_residual`/`radiation_is_tof` の
  算出は runner (GSAS 側) / diagnose_residual (TASK-0002) が担い、本規則は値を消費するだけ。
- frozen 非破壊: `ResidualFeatures` は frozen のまま。新フィールドは末尾追加・既定 0/空で
  後方互換 (EDGE-001 縮退。旧 feature は既定 0.0 でシグナルを立てない)。
- 決定論 (NFR-102/REQ-402): 末尾ソートキーは不変。乱数なし。同一入力でビット同一。
- 材料固有結論を焼き込まない (REQ-405 / DD-2): 「TOF は alpha が効く」等は候補列挙の分岐に留め、
  採否は必ず try→revert (`_accept`) が決める。1 提案に束ねない。

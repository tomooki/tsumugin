### 2. per-hist シグナル算出ロジック 🔵
**信頼性**: 🔵 *requirements REQ-101〜106 / architecture.md 内省フィールド表*
**実装ファイル**: `src/tsumugin/refine_loop/diagnose_residual.py`

各ヒストグラム i について、内省フィールドと残差から以下を算出する (フィールド欠落なら該当を非活性):

- **fwhm 系**: `peak_width_ratio[i]` が 1.0 から有意にずれれば幅ずれシグナル (REQ-103)。欠落なら立てない。
- **asymmetry**: `asymmetry_metric[i]` が tol 超で非対称/位置ズレシグナル (REQ-101)。
- **intensity_bias**: `intensity_bias_metric[i]` が tol 超 (系統 obs>calc) で選択配向シグナル (REQ-102)。
- **bg_extrema (overfit)**: `bg_extrema[i]` が過多 (背景係数に対し極値数が閾値超) で減項シグナル (REQ-104)。
- **diverged_uiso**: `atom_uiso[phase]` の値が負 or 発散閾値超の原子ラベルを収集し RestrictUiso 対象に (REQ-105)。
- **absorption_uncertain**: `hist_absorption[i]` の状態から吸収不確実フラグを立てる (SetAbsorption 三択候補源, REQ-106)。
- **radiation_is_tof**: `inp` のヒストグラム放射源から TOF か否かを判定 (非対称候補が alpha/beta か SH/L かの分岐用)。

閾値 (tol・発散閾値・極値過多閾値) はモジュール定数として明示し、材料固有の結論を焼き込まない
(REQ-405 汎用の try→observe 形)。

### 3. 縮退・false-positive ガード 🔵
**信頼性**: 🔵 *requirements EDGE-001 / EDGE-102*
**実装ファイル**: `src/tsumugin/refine_loop/diagnose_residual.py`

- 内省フィールドが空 (旧 result) の場合、その源に依存するシグナルは**立てない** (KeyError/IndexError を
  出さず縮退)。EDGE-001。
- 残差配列が空、または全ノイズ (有意な系統成分がない) の場合、どのシグナルも立てない。EDGE-102。
- per-hist ループは index 整合 (残差 hist 数と内省 tuple 長の食い違い) を安全に扱い、短い側で縮退する。

## 注意事項
- numpy コア + GSAS 遅延 import: 本モジュールは numpy のみに依存し GSAS を import しない (REQ-401)。
  内省フィールドの実充填は runner (GSAS 側) の責務。
- frozen dataclass 非破壊: `ResidualFeatures` は frozen を維持し、算出は新インスタンス生成のみ (P2)。
- 決定論 (NFR-102): 乱数を使わず、閾値はモジュール定数で固定。同一入力でビット同一。
- 材料固有の結論を焼き込まない (REQ-405): 閾値超で候補シグナルを立てるだけで、採否は後続の
  try→revert (`_accept`) が決める。
- **依存順**: `ResidualFeatures` の拡張フィールド定義は TASK-0003。本タスクは算出ロジックを実装し、
  TASK-0003 完了後に orchestrator (`_default_diagnose` 差し替えは TASK-0009) へ結線する。

### 1. SetAbsorption SafeAction の追加 (REQ-004) 🔵
**信頼性**: 🔵 *interfaces.py `SetAbsorption` 節 / architecture.md DD-1「限定/値固定」*

`action.py` の SafeAction 群に並べて追加。`HistogramSpec.absorption` (既存フィールド, 既定 0.0) を
`value` に設定し、`refine=True` なら吸収解放段を `extra_stages` に足す。範囲外 `hist_id` は既存
`SetLimits` に倣い `IndexError`。
**実装ファイル**: `src/tsumugin/refine_loop/action.py`

```python
@dataclass(frozen=True)
class SetAbsorption(SafeAction):
    """ヒストグラムの吸収を値固定 or 解放する(free/物理/0 の三択トライ)。

    :param hist_id: 対象ヒストグラム索引(0 始まり)
    :param value: 設定する吸収初期値(物理値/0 等)
    :param refine: True なら "absorption" 解放段を extra_stages に追加、False なら固定
    """

    hist_id: int
    value: float = 0.0
    refine: bool = False

    def apply(self, inp: AnalysisInput) -> AnalysisInput:
        if not (0 <= self.hist_id < len(inp.histograms)):
            raise IndexError(f"hist_id={self.hist_id} が範囲外 (n={len(inp.histograms)})")
        hists = list(inp.histograms)
        hists[self.hist_id] = dataclasses.replace(hists[self.hist_id], absorption=self.value)
        extra = inp.extra_stages
        if self.refine:
            stage = RefinementStage(
                label="abs", flags={"absorption": True}, note="SetAbsorption(refine)"
            )
            extra = (*extra, stage)
        return dataclasses.replace(inp, histograms=tuple(hists), extra_stages=extra)
```

- `RefinementStage` は `tsumugin.autorietveld` から既に action.py へ import 済み (`HistogramSpec`/
  `PhaseSpec`/`RefinementStage`)。`HistogramSpec.absorption` は既存フィールド。
- 範囲外 `hist_id` を `IndexError` にする点は既存 `SetLimits.apply` と一貫させる (TC-004-E01)。

### 2. propose_next_actions に吸収不確実 → 3 択規則を追加 (REQ-106) 🔵
**信頼性**: 🔵 *interfaces.py REQ-106 節 / dataflow.md S6 (C6)*

`diagnostics.py` の import に `SetAbsorption` を足し、`absorption_uncertain` が真なら
**free / 物理値 / 0** の 3 候補を列挙する。物理値の初期値は診断側が渡す (材料固有値は焼き込まない;
無ければ現値または 0 を使い、refine で解放して探索させる)。
**実装ファイル**: `src/tsumugin/refine_loop/diagnostics.py`

```python
# 吸収寄与が不確実 → free/物理/0 の 3 択トライ (SetAbsorption, REQ-106, DD-2)
if f.absorption_uncertain:
    hid = f.hist_id
    for label, action, note in (
        ("abs_free", SetAbsorption(hid, 0.0, refine=True), "自由精密化(0 から解放)"),
        ("abs_phys", SetAbsorption(hid, absorption_hint, refine=False), "物理値で固定"),
        ("abs_zero", SetAbsorption(hid, 0.0, refine=False), "0 で固定(無補正)"),
    ):
        proposals.append(
            ActionProposal(
                action=action,
                rationale=f"hist{hid}: 吸収寄与が不確実 → {note} を試行 (別候補; 採否は try→revert)",
                priority=0.6,
                evidence={"signal": "absorption", "kind": label, "hist_id": hid},
                safe=True,
            )
        )
```

- `absorption_hint` は `propose_next_actions` の引数 (既定 0.0)。材料固有の物理吸収値は焼き込まず、
  呼び出し側 (診断 / ③) が渡す。無指定なら 0 になり、実質 free と zero の 2 有効候補+同値になるが、
  規則としては常に 3 候補を列挙する (DD-2/REQ-405 結論を焼き込まない)。
- 3 候補は同 priority のため末尾ソートで安定に並ぶ (すべて `SetAbsorption`、列挙順を保つ安定ソート)。
- 末尾ソートキー (`(not p.safe, -p.priority, type(p.action).__name__)`) は不変 (REQ-402)。

### TC-106-01: 吸収不確実で 3 提案列挙 🔵

## 注意事項（numpy コア/GSAS 遅延/frozen 非破壊/決定論 NFR-102/材料固有結論を焼き込まない REQ-405）
- numpy コア + GSAS 遅延: `action.py`/`diagnostics.py` は純データ層 (numpy のみ)。GSAS import を
  持ち込まない。`absorption_uncertain`/物理吸収値の算出・供給は runner (GSAS 側) / 診断が担う。
- frozen 非破壊 (P2): `SetAbsorption` は frozen。`apply` は `dataclasses.replace` の純変換で入力を破壊
  しない。上書き API を足さない。
- 決定論 (NFR-102/REQ-402): 末尾ソートキーは不変。乱数なし。同一入力でビット同一。
- 材料固有結論を焼き込まない (REQ-405 / DD-2): どの吸収扱い (free/物理/0) が正しいかは結論せず、
  3 候補を列挙して try→revert (`_accept`) が採否を決める。物理値は診断/③ が渡す。

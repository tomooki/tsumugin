initial_phases)`。フロー: frame0 は StagedRefinementEngine フル確立 (first_frame_staged) →
後続は直近成功フレーム warm start + backend.refine 直呼び (scale+lattice, seq_max_cycles) →
フレーム指標 → detect_changepoint → 発火時 HypothesisTreeSearch (候補=現行相+候補プール、
共有 ledger) → evidence 改善時のみ採択 (adopt/reject を ledger 記録) → LifecycleTracker →
Trajectory 組立。Hypothesis.frame_range に採択区間。orchestration="native" は NotImplementedError。

## タスク概要
`joint/engine.py`: `refine_joint(backend, model, *, weighting, max_cycles=20, ledger=None)
-> RefinementResult` と `refine_joint_detailed(...) -> JointRefinementResult`。
【SimulatedBackend】各ヒストを `backend.refine` (ヒスト独立 free) → χ² 合算、共有構造は χ² 和で更新
(簡易ブロック座標降下, D2)。集約 chi2=Σχ²、rwp=結合 Rwp、共有構造 phases(±σ) を単一 RefinementResult
へ集約 (rank/evidence 互換, D1)。ヒスト別値は per_histogram と aggregate.globals ("hist0.rwp" 等) 双方に持つ。
【GSASIIBackend】GSAS-II ネイティブのマルチヒストグラム機能への接続点を配線 (v1 は @gsas smoke 1 本)。
【失敗の非例外化】1 ヒスト精密化失敗を chi2=inf へ変換し集約 chi2=inf へ伝播、warnings に失敗ヒスト index
と σ 由来を明示 (例外化しない, EDGE-001)。

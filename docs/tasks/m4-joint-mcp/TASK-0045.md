## タスク概要
`mcp/server.py` (**SDK 依存の薄いアダプタ層**): `create_mcp_server(session) -> object` が MCP Server を
構築し `MCP_TOOLS` の 8 ツールを実処理関数へ配線する。【SDK 遅延 import】`import tsumugin.mcp.server`
自体は mcp SDK 未導入でも成功する (WebUIUnavailableError と対称)。`create_mcp_server` /
`serve_stdio` / `serve_local` 呼び出し時にのみ mcp SDK を import し、未導入なら `MCPUnavailableError`
を送出 (実処理関数 tools.py は SDK 非依存で動作, REQ-102/EDGE-009)。`serve_stdio(session)` (既定・ローカル)、
`serve_local(session, *, host="127.0.0.1", port=0)` (無認証ネットワーク公開しない, REQ-303/405)。
SDK 依存テストは `@pytest.mark.mcp` 等で分離、コア import は numpy のみで tsumugin が import 可能を担保。

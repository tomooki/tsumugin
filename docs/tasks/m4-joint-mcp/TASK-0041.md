## タスク概要
`joint/verification.py`: `JointVerificationResult` (verified: tuple[Hypothesis,...] /
joint_results: Mapping[str, JointRefinementResult] / recommendations: Mapping[str, tuple[...]] / warnings)。
`verify_survivors(backend, search_result, histograms, *, evidence=None, weighting, contrast,
ledger=None) -> JointVerificationResult`: プライマリ探索 (SearchResult) を**不変**とし、生存仮説
(良好解) のみを `JointRefinementModel` へ組み `refine_joint_detailed` で検証精密化、`recommend_occupancy_release`
でコントラスト推奨も付す。**探索段を joint 化しない** (REQ-202)。木探索は HypothesisTreeSearch を
プライマリ 1 本で実行済みという前提で、その SearchResult を入力に取る (探索は書き換えない)。

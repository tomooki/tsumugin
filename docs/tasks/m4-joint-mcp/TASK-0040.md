## タスク概要
`joint/contrast.py`: 軽量静的テーブル `NEUTRON_B_TABLE` (元素→中性子コヒーレント散乱長 b [fm]) と
`XRAY_Z_TABLE` (元素→原子番号 Z) を重依存なしで同梱 (REQ-403)。`OccupancyReleaseRecommendation`
(phase_index/site/elements/contrast/param_name/rationale)、`ContrastConfig` (contrast_threshold=0.15)。
`recommend_occupancy_release(phases, model, *, config, ledger=None) -> tuple[...]`:
各サイト占有元素対 (A,B) で f_norm=f_A/(f_A+f_B)・b_norm=b_A/(|b_A|+|b_B|) を計算し
|f_norm−b_norm| >= threshold のサイトを検出。【joint 条件】ヒスト数 ≥ 2 かつ probe 種別 ≥ 2 のときのみ発火、
単一ヒストは空 (REQ-104/EDGE-004)。全サイト閾値未満は空・警告なし (REQ-103/EDGE-003)。各推奨を
`ledger.append("contrast_occupancy_recommend", {...})` で理由付き記録。**提案のみ・自動適用しない**。
決定論: 元素は記号昇順・サイトは占有率キー昇順で評価。

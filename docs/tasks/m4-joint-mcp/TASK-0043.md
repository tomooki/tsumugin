## タスク概要
`chem/ranking.py`: `rank_with_plausibility(hypotheses, backend, *, modules=(), context,
phase_refs=None, weights=None, temperature=1.0, close_threshold=10.0, ledger=None)
-> tuple[RankedHypothesis,...]`。【配線 (D5)】まず `evidence.ranking.rank` で素の順位・確率 p を取得。
modules 非空なら各仮説の各相を `score` → `combine_plausibility` で相スコア s∈[0,1] を合成し p'=p·s で
確率補正 → 再正規化・並べ替え。modules 空なら素の rank をそのまま返す (REQ-105/EDGE-006)。
【最重要不変条件】スコアは**降格のみ**に使い、候補の除外・rejected 化を行わない。低スコア相も rank から
消えない (REQ-019/EDGE-005)。降格スコアと理由を ledger 記録。決定論: module id 昇順・相順は入力順。

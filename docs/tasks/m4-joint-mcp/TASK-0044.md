## タスク概要
`mcp/tools.py` (**SDK 非依存の実処理層**): `AnalysisSession` facade (project/backend/selection/
ledger/snapshots/evidence/search_result/trajectory)。8 ツール実処理関数を M0〜M3 資産へ委譲 —
`submit_analysis` (単一→analyze_single_pattern / joint→探索→verify_survivors・ledger 記録)、
`list_hypotheses` (SearchResult.to_summary/rank)、`compare_hypotheses` (rank)、`accept_hypothesis`
(FinalSelectionEngine.accept・human モードで by=agent は accepted 化拒否→recommend_only, REQ-106/EDGE-010)、
`revert` (FinalSelectionEngine.revert=superseded 化・追記型・件数減らない, REQ-024)、`get_trajectory`
(Trajectory・CSV)、`export_gpx` (export.gpx・GSASUnavailableError→{"status":"error"} 変換, EDGE-011)、
`run_mem` (mem.run_mem_boundary へ委譲)。全応答は素の型 dict。全状態変更は理由付き ledger 記録。
`MCP_TOOLS` レジストリ (8 ツール名→関数・単一情報源)。
`mcp/mem.py`: `run_mem_boundary(session, *, placeholder=False, **params)` — 既定 MEMUnavailableError
送出 / placeholder=True でプレースホルダ dict、いずれも状態変更・破壊的 ledger 追記なし (M5 境界)。

## タスク概要
`MatchResult`, `match_score(candidate_peaks, observed_peaks, *, tol_deg=0.15)`,
`UnmatchedPeakReport` と未マッチ抽出関数を実装。スコア = 候補ピーク一致率と
観測強度被覆率の等重み平均 (設計 D 参照 🟡)。候補ピークは backend の
`peak_positions()` (SimulatedBackend 実装済み) から生成する。

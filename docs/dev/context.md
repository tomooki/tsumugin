## Overview

Tsumugin — 粉末回折の多仮説・全自動 Rietveld 解析プラットフォーム。
バックエンドは GSAS-II (`GSASIIscriptable`) を想定するが、コアは `RefinementBackend`
抽象で分離し、GSAS-II 非導入環境でも `SimulatedBackend` で全パイプラインを検証できる。
本コンテキストは **M0 (PoC)** スコープ。仕様は [docs/tsumugin_spec_v0.3.md](../tsumugin_spec_v0.3.md)。

### Data Modeling
- `dataclasses` を基本とする。バックエンド境界は `typing.Protocol` で定義（🔵 spec P7）。
- 不変性を優先: モデルの更新は新インスタンス生成 + Snapshot 追記（🔵 spec P2）。

### Error Handling
- ドメイン例外は `tsumugin.errors` に集約（`TsumuginError` 基底）。
- ガードレール発動は例外を投げず結果オブジェクト(`GuardOutcome`)で表現し ledger 記録（🔵 FR-214）。

### Non-negotiable Invariants (spec 由来)
- **P2 / NFR-101**: 破壊的操作の API を実装しない。全状態は追記 + Snapshot で revert 可能。
- **NFR-105**: ledger は追記専用 + ハッシュチェーン。
- **NFR-102**: 乱数種固定で再現性（ビット同一を目標）。
- **FR-412 教訓**: スコアは降格のみ、候補の除外はしない（M0 では evidence ランキングに反映のみ）。

## Additional Notes

- GSAS-II 2.0 導入済み。方式: ソースツリー (C:\Users\tomoo\G2) + venv の `gsas2-source.pth` +
  ビルド済みバイナリ (~/.GSASII/GSASII-bin/win_64_p3.12_n2.2、buildtools リリース由来)。
  import は `from GSASII import GSASIIscriptable` (パッケージ形式)。
  ランタイム依存は `uv sync --extra gsas`（プレーンな `uv sync` は extra を外すので注意）。
- `GSASIIBackend` は refine (scale=HAP相分率 / lattice.*=Cell) と simulate (noise-free Ycalc) を実装済み。
  profile 以降の suffix は M2+ で拡張。
- 既知の無害な警告: `~/.GSASII/config.ini` (ユーザーの既存ファイル、cp932) を GSAS-II が UTF-8 で
  読めず起動時に "Error reading {cfgfile}" を出すが動作に影響なし (upstream の表示バグ含む)。
- M0 スコープ外（M1 以降）: 多仮説木探索、シーケンシャル、operando、MEM、nested sampling、Web/REST/MCP。
